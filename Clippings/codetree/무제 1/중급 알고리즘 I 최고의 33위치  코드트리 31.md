Lesson 2. 격자 안에서 한 칸씩 전진하는 DP

## 정수 사각형 최댓값의 최소

Easy

40XP

평균 19분

63% 정답률

총 제출 1,414회

$N \times N$ 행렬이 주어졌을 때, $(1, 1)$ 에서 시작하여 오른쪽 혹은 밑으로만 이동하여 $(N, N)$ 으로 간다고 했을 때 거쳐간 위치에 적혀있는 수들 중 최댓값을 최소로 하는 프로그램을 작성해보세요.

### 입력

첫째 줄에는 $N$ 이 주어집니다.

두 번째 줄 부터 $N$ 개의 줄에 각각 각 행에 해당하는 $N$ 개의 정수 값이 공백을 사이에 두고 주어집니다.

### 제한 조건

- $1 \le N \le 100$
- $1 \le \texttt{행렬에 주어지는 수} \le 1\,000\,000$

### 출력

가능한 경로의 수들 중 최댓값의 최솟값을 출력합니다.

### 입력 예제

### 예제 1

입력

```
3
1 4 3
3 4 5
5 4 2
```

출력

```
4
```

예제 설명

접기

첫 번째 예제의 경우 다음과 같이 이동하면 지나는 경로에 적혀있는 수들 중 최댓값이 $4$ 가 되며, 더 작게 답을 만들 수가 없습니다.

![](https://contents.codetree.ai/problems/2488/images/problems-f2bfe1c0-1e1a-4dff-9a4d-2db60f98faa2.png)

### 예제 2

입력

```
3
5 6 7
6 5 4
5 7 1
```

출력

```
6
```
