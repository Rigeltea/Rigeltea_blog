## 회전 마법진

Hard

90XP

평균 180분

64% 정답률

총 제출 153회

마법사 라엘은 고대 마법의 탑에 도전하고 있습니다. 탑에는 마법진 $N$ 개가 위에서 아래로 쌓여 있으며, 위에서부터 $1$ 번, $2$ 번, $\ldots$, $N$ 번 순으로 번호가 매겨져 있습니다.

각 마법진에는 $0$ 부터 $9$ 까지의 숫자 $10$ 개가 시계 방향으로 배열되어 있고, 고정된 표식이 그중 하나의 숫자를 가리킵니다. 이 표식이 가리키는 숫자를 그 마법진의 **상태** 라고 합니다.

![Image](https://contents.codetree.ai/problem_factory/images/2e22e187-693f-42f2-8d76-d1e9099418c7.webp)

라엘은 다음 두 종류의 회전 조작만 수행할 수 있으며, 각 조작은 $1$ 회의 회전으로 셉니다.

- **반시계 방향 회전**: $i$ 번 마법진을 반시계 방향으로 $1$ 칸 회전시키면 $i$ 번 마법진의 상태가 $1$ 증가합니다 (숫자 $9$ 의 다음은 $0$ 입니다). 동시에 $i$ 번보다 아래에 있는 마법진, 즉 $i + 1$ 번부터 $N$ 번까지 모두 반시계 방향으로 $1$ 칸씩 함께 회전하여 각자의 상태도 $1$ 씩 증가합니다.
- **시계 방향 회전**: $i$ 번 마법진을 시계 방향으로 $1$ 칸 회전시키면 $i$ 번 마법진의 상태만 $1$ 감소합니다 (숫자 $0$ 의 이전은 $9$ 입니다). 다른 마법진의 상태에는 영향을 주지 않습니다.

![Image](https://contents.codetree.ai/problem_factory/images/b0373e57-b7ba-4447-a899-2a44cd3f05a0.webp)

라엘에게는 마법진들의 현재 상태와 목표 상태가 주어집니다. 현재 상태에서 목표 상태로 바꾸기 위해 필요한 최소 회전 횟수를 구해주세요.

예를 들어, 탑에 세 개의 마법진이 있고 ($N = 3$), 현재 상태가 $111$ 이며 목표 상태가 $323$ 이라면 최소 회전 횟수는 $3$ 입니다. $1$ 번 마법진을 반시계 방향으로 $2$ 번 회전시키면 $1$ 번뿐 아니라 $2$ 번, $3$ 번도 함께 두 칸씩 회전하여 상태가 $333$ 이 되고, 이어서 $2$ 번 마법진을 시계 방향으로 $1$ 번 회전시키면 상태가 $323$ 이 됩니다.

### 입력

첫 번째 줄에 마법진의 개수 $N$ 이 주어집니다.

두 번째 줄에는 마법진들의 현재 상태를 나타내는 길이 $N$ 의 숫자열이 주어집니다. 문자열의 $i$ 번째 문자는 $i$ 번 마법진의 현재 상태입니다.

세 번째 줄에는 마법진들의 목표 상태를 나타내는 길이 $N$ 의 숫자열이 주어집니다. 문자열의 $i$ 번째 문자는 $i$ 번 마법진의 목표 상태입니다.

각 문자는 $0$ 부터 $9$ 까지의 숫자입니다.

### 제한 조건

- $3 \le N \le 10\,000$

### 출력

첫 번째 줄에 현재 상태에서 원하는 상태로 변환하기 위한 최소 회전 횟수를 출력합니다.

### 입력 예제

### 예제 1

입력

```
3
111
323
```

출력

```
3
```
