Lesson 4. 아이템을 적절히 고르는 문제

## 경험치를 빠르게 얻기

Hard

90XP

평균 135분

50% 정답률

총 제출 653회

$N$ 개의 퀘스트 정보가 주어졌을 때 수행할 퀘스트를 잘 골라 각 퀘스트로부터 얻은 경험치의 총 합이 $M$ 이상이며 걸리는 총 시간이 최소가 되도록 하는 프로그램을 작성해보세요. 단, 동일한 퀘스트는 여러 번 진행할 수 없음에 유의합니다.

### 입력

첫 번째 줄에는 $N$ 과 $M$ 이 공백을 사이에 두고 주어집니다.

두 번째 줄부터는 $N$ 개의 줄에 걸쳐 각 퀘스트의 정보 $(e,\ t)$ 가 공백을 사이에 두고 주어집니다. 이는 해당 퀘스트를 깨면 경험치를 $e$ 만큼 얻을 수 있으며, 퀘스트를 깨는데 시간 $t$ 만큼 소요됨을 뜻합니다. 퀘스트는 $1$ 번부터 $N$ 번까지 차례대로 주어집니다.

### 제한 조건

### 출력

경험치를 $M$ 이상 얻기 위해 필요한 최소 시간을 출력합니다. 만약 불가능하다면 $-1$ 을 출력합니다.

### 입력 예제

### 예제 1

입력

```
3 5
2 3
5 4
3 2
```

출력

```
4
```

예제 설명

접기

이 예제에서는 $2$ 번 퀘스트만 진행하면 경험치 $5$ 를 얻으며 $4$ 만큼의 시간이 걸립니다.

### 예제 2

입력

```
4 14
5 6
6 5
8 10
5 2
```

출력

```
13
```

예제 설명

접기

이 예제에서는 $1$, $2$, $4$ 번 퀘스트를 진행하면 경험치 $16$ 을 얻으며 $13$ 만큼의 시간이 소요됩니다.

### 제한

• Time Limit: 1000 ms

• Memory Limit: 128 MiB
