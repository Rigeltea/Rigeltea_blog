Lesson 1. K개 중 하나를 N번 선택하기(Simple)

기본 문제에서는 단계별 학습을 위해 각 문제가 하나의 기본개념과 짝을 이룹니다. 연습 문제와 테스트 문제에서는 쉽게 복습할 수 있도록 모든 개념이 함께 제공됩니다.

## K개 중 하나를 N번 선택하기 (Simple)

어떤 함수 `f` 가 해당 함수를 구현하는 데 동일한 함수 `f` 를 다시 이용하는 경우, 이를 `재귀 함수` 라고 부릅니다. 만약 재귀 함수에 대해 잘 모르신다면, Novice Mid 문제집의 [재귀함수 단원](https://www.codetree.ai/missions/5/concepts/40/problems/repeated-output-2/introduction) 을 공부하시고 나서 이 글을 읽는 것을 추천드립니다.

예를 들어 1부터 N까지 자연수의 합을 구하는 코드를 작성하려고 합니다. 이는 for문을 이용해 작성할 수도 있지만, 재귀함수를 이용해 작성하는 것 역시 가능합니다. 재귀함수는 크게 **종료 조건** 과 **재귀 호출** 부분으로 나뉜다는 것을 다시 상기시켜 봅시다.

```python
def get_sum(n):
    # 종료 조건
    if n == 1:
        return 1

    # 재귀 호출
    return n + get_sum(n - 1)

n = 5
print(get_sum(n))
```

위에서 작성한 1부터 n까지의 합을 구하는 `get_sum(n)` 이라는 재귀함수는, 다음과 같이 동작할 것입니다.

대부분의 알고리즘 문제들은 원하는 모든 조합을 만들어 그 중 문제에서 원하는 답을 고르는 식으로 해결이 가능합니다. 만약 n 제한이 작고, 모든 조합을 만드는 데 걸리는 시간이 문제에서 주어진 제한 시간보다 더 작다면, 항상 모든 조합을 다 만들어 보는 것이 가독성 측면에서나, 코드를 작성하는 입장에서 가장 좋다고 할 수 있을 것입니다. 다만, (1, 1, 1, 1, 1), (1, 1, 1, 1, 2), (1, 1, 1, 1, 3), (1, 1, 1, 2, 1), (1, 1, 1, 2, 2),.. 등 여러 가능한 순열과 조합을 만드는 것을 for문 만을 이용하여 표현하기에는 많은 어려움이 있습니다. 이런 경우에 재귀함수를 이용하면 원하는 모든 순열과 조합을 만들어 낼 수 있습니다.

예를 들어 n이 주어졌을 때, n자리의 2진수를 전부 출력하는 코드를 작성해보려고 합니다. 단, 이 2진수들을 전부 증가하는 순서대로 출력해보려고 합니다. n이 2인 경우라면, 00, 01, 10, 11 순서로 출력이 되어야 할 것입니다.

이를 다음과 같이 접근해보려고 합니다. 예를 들어 n이 3이었다면, 3자리를 만들어야 하며 각 자리마다 0 혹은 1이 채워져야 합니다. 따라서 먼저 첫 번째 자리에서 시작하여 0을 넣을지, 1을 넣을지 결정합니다. 이후 두 번째 자리에 0, 1 중 하나를 선택하여 적어주고, 세 번째 자리에도 0, 1 중 하나를 적어줍니다. 세 번째 자리까지 채워졌다면 현재 숫자(그림에서의 011)를 출력한 뒤, 그 다음 숫자를 만드는 것을 재귀적으로 반복합니다.

![](https://contents.codetree.ai/problems/24/images/introductions-14fe93b0-33ca-4ce6-904c-749612143320.png)

원하는 2진수 조합을 전부 만들어 보기 위해 `choose(curr_num)` 이라는 함수를 이용해보겠습니다. 함수를 이용할 때는 **함수의 정의** 를 명확히 하는 것이 그 무엇보다도 중요합니다. choose 함수를 다음과 같이 정의해보겠습니다.

```jsx
choose(curr_num): curr_num번째 위치에 0 혹은 1을 선택하는 함수
```

아직 아무 숫자도 골라보지 못한 상황에서 시작해야 하므로, 함수 정의상 처음 시작은 `choose(1)` 이 됩니다. 편의상 choose 함수를 `C` 로 적어보도록 하겠습니다.

![](https://contents.codetree.ai/problems/24/images/introductions-0bf82b7e-0e83-4979-b99c-91a6b5ae14e9.png)

첫 번째 자리에 들어갈 수 있는 숫자는 0 혹은 1 이므로, `C(1)` 이라는 함수는 0또는 1을 선택해줘야 합니다. 선택을 진행한 뒤에는 이제 두 번째 자리를 정해야 하므로 `C(2)` 를 호출해줍니다.

![](https://contents.codetree.ai/problems/24/images/introductions-aaccd25b-78de-4cbd-959e-29694daa77a9.png)

이제 `C(2)` 가 0또는 1을 선택한 뒤 다시 `C(3)` 을 호출해주고, `C(3)` 역시 마찬가지 과정을 거쳐 `C(4)` 를 호출하게 됩니다.

`C(4)` 에 오게 되었다면, 함수 정의상 `네 번째 자리에 들어갈 숫자를` 결정해야 합니다. 하지만 N = 3이었기 때문에, 3번째 자리까지만 결정하면 되므로 더 진행하지 않고 **현재 만들어진 리스트를 출력한 뒤**, `return` 를 통해 퇴각하면 됩니다. 즉, 이 재귀함수 에서는 curr\_num == n + 1인 경우가 종료조건이 됩니다. 또한 재귀함수에서는 퇴각을 진행할 때, 진입 직전에 arr에 적었던 숫자를 하나 빼줘야 합니다. 그래야 그 다음 숫자에 대해 공정하게 기회를 줄 수 있게 됩니다.

먼저 `choose(curr_num)` 함수를 정의합니다. 함수는 크게 종료 조건과, 재귀 함수 호출 코드로 구분되어져 있으며 아래와 같은 정의를 가집니다.

```jsx
choose(curr_num): curr_num번째 위치에 0 혹은 1을 선택하는 함수
```

```python
n = 3
answer = []

def print_answer():
    for elem in answer:
        print(elem, end=" ")
    print()

def choose(curr_num):
    # 종료 조건
    if curr_num == n + 1:
        print_answer()
        return
    
    # 0을 선택했을 때 재귀 호출
    answer.append(0)
    choose(curr_num + 1)
    answer.pop()

    # 1을 선택했을 때 재귀 호출
    answer.append(1)
    choose(curr_num + 1)
    answer.pop()

    return

choose(1)
```

재귀 함수 코드를 살펴보겠습니다.

먼저 종료 조건은 `curr_num == n + 1` 조건을 만족하는 경우입니다. 이때 리스트에 적혀있는 값들을 출력하면 됩니다.

현재 curr\_num 자리에 0을 넣는 경우에는 리스트의 가장 끝에 숫자 0을 적어주고, 그 다음 자릿수인 curr\_num + 1에 해당하는 함수 `choose(curr_num + 1)` 을 호출해 줍니다. 그 이후에 함수를 빠져나온 경우를 생각해, 리스트의 가장 끝에 적혀있는 숫자를 비워주는 코드를 작성해줍니다.  
curr\_num 자리에 1을 넣는 경우 역시 비슷하게 처리가 가능합니다.

def choose(curr_num):
