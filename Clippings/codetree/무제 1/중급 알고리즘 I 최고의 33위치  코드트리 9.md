Lesson 2. K개 중 하나를 N번 선택하기(Conditional)

기본 문제에서는 단계별 학습을 위해 각 문제가 하나의 기본개념과 짝을 이룹니다. 연습 문제와 테스트 문제에서는 쉽게 복습할 수 있도록 모든 개념이 함께 제공됩니다.

## K개 중 하나를 N번 선택하기 (Conditional)

[n자리 이진수를 만드는 재귀함수](https://www.codetree.ai/missions/2/concepts/3/problems/n-permutations-of-k-with-repetition/introduction) 는 다음과 같이 구현이 가능하다고 했었습니다. 그 중에서도 for문을 이용하면, 이후 k개중 1개를 n번 뽑는 코드를 쉽게 구현할 수 있다고 배웠습니다.

```python
def choose(curr_num):
    # 종료 조건
    if curr_num == n + 1:
        print_answer()
        return
    
"""
    # 0을 선택했을 때 재귀 호출
    answer.append(0)
    choose(curr_num + 1)
    answer.pop()

    # 1을 선택했을 때 재귀 호출
    answer.append(1)
    choose(curr_num + 1)
    answer.pop()
"""

    # 반복문을 이용해 0, 1을 선택했을 때 재귀 호출
    for select in range(2):
        answer.append(select)
        choose(curr_num + 1)
        answer.pop_back()

    return
```

이때 만약 n자리 2진수 중 **0이 인접해서 등장하지 않는** 수만 구해 출력하는 코드는 어떻게 작성해볼 수 있을까요? 이전 코드와 개형은 거의 비슷하지만, 0, 1을 선택하는 과정에서 약간의 변화를 주면 되지 않을까요?

```
0 0 0 <- 불가능
0 0 1 <- 불가능
0 1 0
0 1 1
1 0 0 <- 불가능
1 0 1
1 1 0
1 1 1
```

```python
def choose(curr_num):
    # 종료 조건
    if curr_num == n + 1:
        print_answer()
        return
    
    # 0을 선택했을 때 재귀 호출
    # 선택할 때 특정 조건들을 고려해야한다
    answer.append(0)
    choose(curr_num + 1)
    answer.pop()

    # 1을 선택했을 때 재귀 호출
    answer.append(1)
    choose(curr_num + 1)
    answer.pop()

    return
```

조금만 생각해보면, **0을 추가하기 위한 조건** 만 넣어주면 된다는 사실을 알 수 있습니다. 1의 경우에는 항상 추가해도 되지만, 인접한 00을 만들지 않기 위해서는 0의 경우에 1) 최초로 추가하는 숫자로서의 0이거나 2) 바로 직전의 숫자가 0이 아니었을 경우에만 추가가 가능합니다. 따라서 해당 조건을 추가하면 됩니다.

```python
def choose(curr_num):
    # 종료 조건
    if curr_num == n + 1:
        print_answer()
        return
    
    # 0을 선택했을 때 재귀 호출
    # 선택할 때 특정 조건들을 고려해야한다
    if curr_num == 1 or answer[-1] != 0:
        answer.append(0)
        choose(curr_num + 1)
        answer.pop()

    # 1을 선택했을 때 재귀 호출
    answer.append(1)
    choose(curr_num + 1)
    answer.pop()

    return
```
