Lesson 3. String Matching

## 최단 공통 상위수열

Easy

40XP

평균 31분

51% 정답률

총 제출 310회

두 문자열 $S$ 와 $T$ 가 주어졌을 때, 이 두 문자열의 상위수열인 가장 짧은 문자열의 길이를 찾는 프로그램을 작성하세요.

상위수열은 다음과 같이 정의합니다.

- 문자열 $A$ 가 문자열 $B$ 의 부분수열이면, 문자열 $B$ 는 문자열 $A$ 의 상위수열입니다.

예를 들어, $S = "code"$, $T = "tree"$ 일 경우, $"codtree"$ 는 $"code"$ 와 $"tree"$ 를 모두 부분 수열로 가지므로, 두 문자열의 상위수열입니다.

### 입력

첫 번째 줄에 문자열 $S$ 가 입력됩니다.

두 번째 줄에 문자열 $T$ 가 입력됩니다.

### 제한 조건

- $1 \le \texttt{문자열 } S,\ T \texttt{의 길이} \le 1\,000$
- 문자열 $S$, $T$ 는 모두 알파벳 소문자만으로 이루어져 있습니다.

### 출력

첫 번째 줄에 두 문자열 $S$ 와 $T$ 의 상위수열인 가장 짧은 문자열의 길이를 출력합니다.

### 입력 예제

### 예제 1

입력

```
code
tree
```

출력

```
7
```

• Time Limit: 1000 ms

• Memory Limit: 128 MiB
