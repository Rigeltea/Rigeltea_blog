Lesson 4. 순열 만들기

기본 문제에서는 단계별 학습을 위해 각 문제가 하나의 기본개념과 짝을 이룹니다. 연습 문제와 테스트 문제에서는 쉽게 복습할 수 있도록 모든 개념이 함께 제공됩니다.

## 순열 만들기

n이 주어졌을 때, 1부터 n까지의 수들을 이용해 중복 없이 모든 수들이 나오는 순열을 출력하는 코드를 작성해보려고 합니다. 단, 이 순열들을 전부 증가하는 순서대로 출력해보려고 합니다. n이 3인 경우라면, 123, 132, 213, 231, 312, 321 순서로 출력이 되어야 할 것입니다.

이를 다음과 같이 접근해보려고 합니다. 예를 들어 n이 3이었다면, 3자리를 만들어야 하며 각 자리마다 1, 2 혹은 3이 채워져야 합니다. 따라서 먼저 첫 번째 자리에서 시작하여 1, 2, 3 중 어떤 수를 넣을지 결정합니다. 이후 두 번째 자리에 1, 2, 3 중 아직 선택되지 않은 숫자 중 하나를 선택하여 적어주고, 세 번째 자리에도 1, 2, 3 중 아직 선택되지 않은 숫자를 하나를 적어줍니다. 세 번째 자리까지 채워졌다면 현재 숫자(그림에서의 231)를 출력한 뒤, 그 다음 숫자를 만드는 것을 재귀적으로 반복합니다. **이때 이미 선택된 숫자를 다시 선택하지 않게 하기 위해 visited 배열을 이용합니다.**

원하는 N! 순열을 전부 만들어 보기 위해 `choose(curr_num)` 이라는 함수를 이용해보겠습니다. 함수를 이용할 때는 **함수의 정의** 를 명확히 하는 것이 그 무엇보다도 중요합니다. choose 함수를 다음과 같이 정의해보겠습니다.

```jsx
choose(curr_num): curr_num번째 위치에 1~N 사이의 수 중 아직 선택되지 않은 수를 골라주는 함수
```

아직 아무 숫자도 골라보지 못한 상황에서 시작해야 하므로, 함수 정의상 처음 시작은 `choose(1)` 이 됩니다. 편의상 choose 함수를 `C` 로 적어보도록 하겠습니다.

첫 번째 자리에 들어갈 수 있는 숫자는 1, 2, 3 중 하나이므로, `C(1)` 이라는 함수는 1, 2, 3 중 하나를 선택해줘야 합니다. 선택을 진행한 뒤에는 이제 두 번째 자리를 정해야 하므로 `C(2)` 를 호출해줍니다.

이제 `C(2)` 가 이미 선택된 1을 제외한 2 또는 3을 선택한 뒤 다시 `C(3)` 을 호출해주고, `C(3)` 역시 마찬가지 과정을 거쳐 `C(4)` 를 호출하게 됩니다.

이때 각 과정에 걸쳐 숫자를 선택할 때마다 리스트에 각 숫자를 순서대로 넣어줍니다. 이는 나중에 만들어진 순열을 출력하기 위해 쓰이게 됩니다.

또한 동시에 이미 사용된 숫자를 표시해주기 위해 Visited 배열을 추가적으로 사용합니다.

`C(4)` 에 오게 되었다면, 함수 정의상 `네 번째 자리에 들어갈 숫자를` 결정해야 합니다. 하지만 N = 3이었기 때문에, 3번째 자리까지만 결정하면 되므로 더 진행하지 않고 **현재 만들어진 리스트를 출력한 뒤**, `return` 를 통해 퇴각하면 됩니다. 즉, 이 재귀함수 에서는 curr\_num == n + 1인 경우가 종료조건이 됩니다.

재귀함수에서는 퇴각을 진행할 때, 진입 직전에 arr에 적었던 숫자를 하나 빼주며 동시에 visited 배열에서도 해당 숫자에 대한 체크를 해제 해줍니다. 그래야 그 다음 숫자에 대해 공정하게 기회를 줄 수 있게 됩니다.

이러한 과정을 거쳐 재귀적으로 탐색을 진행하면 원하는 숫자들을 전부 만들어낼 수 있게 됩니다.

이를 코드로 나타내보도록 하겠습니다.

먼저 `choose(curr_num)` 함수를 정의합니다. 함수는 크게 종료 조건과, 재귀 함수 호출 코드로 구분되어져 있습니다.

```python
n = 3
visited = [False] * (n+1)
answer = []

def print_answer():
    for elem in answer:
        print(elem, end=" ")
    print()

def choose(curr_num):
    if curr_num == n + 1:
        print_answer()
        return
    
    for i in range(1, n+1):
        if visited[i]:
            continue
        
        visited[i] = True
        answer.append(i)
        
        choose(curr_num + 1)

        answer.pop()
        visited[i] = False

choose(1)
```

종료 조건은 `curr_num == n + 1` 조건을 만족하는 경우입니다. 이때 리스트에 적혀있는 값들을 출력하면 됩니다.

재귀 함수 호출 부분의 코드를 살펴보겠습니다.  
사전순으로 앞선 경우가 먼저 나와야 하므로 curr\_num 자리에 1부터 n까지의 수를 순차적으로 넣어봅니다. 선택된 숫자가 i라고 한다면 이를 arr에 넣어주고 visited 값을 true로 바꾼 뒤 그 다음 자릿수인 curr\_num + 1에 해당하는 함수 `choose(curr_num + 1)` 을 호출해 줍니다. 그 이후에 함수를 빠져나온 경우를 생각해, 리스트의 가장 끝에 적혀있는 숫자를 비워주고 visited 값을 다시 false로 바꿔주는 코드를 작성해줍니다.
