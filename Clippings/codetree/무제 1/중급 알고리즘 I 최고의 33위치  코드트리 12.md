Lesson 3. N개 중에 M개 고르기(Simple)

기본 문제에서는 단계별 학습을 위해 각 문제가 하나의 기본개념과 짝을 이룹니다. 연습 문제와 테스트 문제에서는 쉽게 복습할 수 있도록 모든 개념이 함께 제공됩니다.

## N개중에 M개 고르기 (Simple)

[n자리 이진수를 만드는 재귀함수](https://www.codetree.ai/missions/2/concepts/3/problems/n-permutations-of-k-with-repetition/introduction) 는 다음과 같이 구현이 가능하다고 했었습니다. 그 중에서도 for문을 이용하면, 이후 k개중 1개를 n번 뽑는 코드를 쉽게 구현할 수 있다고 배웠습니다.

이때 만약 n자리 이진 수 중 1의 개수가 정확히 m개인 수만 구해 출력하는 코드는 어떻게 작성해볼 수 있을까요? 이전 코드와 개형은 거의 비슷하지만, 출력하는 조건에만 약간의 변화를 주면 되지 않을까요?

```
n = 3, m = 2인 경우

0 0 0 <- 출력X
0 0 1 <- 출력X
0 1 0 <- 출력X
0 1 1
1 0 0 <- 출력X
1 0 1
1 1 0
1 1 1 <- 출력X
```

조금만 생각해보면, 종료 조건에서 출력을 하기 전에 1의 개수를 직접 세어 실제 1의 개수가 m인 경우에만 출력을 진행하면 된다는 사실을 알 수 있습니다.

```python
n, m = 3, 2
answer = []

def choose(curr_num):
    if curr_num == n + 1:
        cnt = 0
        for elem in answer:
            if elem == 1:
                cnt += 1

        if cnt == m:
            print_answer()
        return

    answer.append(0)
    choose(curr_num + 1)
    answer.pop()

    answer.append(1)
    choose(curr_num + 1)
    answer.pop()

    return
```

하지만 위 방법으로는 모든 2^n개의 조합에 대해 for문을 n번 돌며 1의 개수를 세기 때문에 총 시간복잡도가 $O(2^n \times n)$ 이 됩니다.

그렇다면 다음과 같이 **지금까지의 1의 개수를 재귀함수의 인자로 정의하여** 해결해보는 것은 어떨까요?

이를 다음과 같이 접근해보려고 합니다. 예를 들어 n이 3이었다면, 3자리를 만들어야 하며 각 자리마다 0 혹은 1이 채워져야 합니다. 따라서 먼저 첫 번째 자리에서 시작하여 0을 넣을지, 1을 넣을지 결정합니다. 이후 두 번째 자리에 0, 1 중 하나를 선택하여 적어주고, 세 번째 자리에도 0, 1 중 하나를 적어줍니다. 이때 진행시에 1의 개수를 같이 재귀함수의 인자로 넘겨주며 진행합니다.

![](https://contents.codetree.ai/problems/21/images/introductions-51aba6b8-0dbd-457e-9ceb-7d555372e9b5.png)

원하는 2진수 조합을 지금까지 만든 1의 개수를 관리하며 전부 만들어 보기 위해 `choose(curr_num, cnt)` 이라는 함수를 이용해보겠습니다. 함수를 이용할 때는 **함수의 정의** 를 명확히 하는 것이 그 무엇보다도 중요합니다. choose 함수를 다음과 같이 정의해보겠습니다.

```jsx
choose(curr_num, cnt): 지금까지 선택한 1의 개수가 cnt개라 했을 때, 
1
```

아직 아무 숫자도 골라보지 못한 상황에서 시작해야 하므로, 함수 정의상 처음 시작은 `choose(1, 0)` 이 됩니다. 편의상 choose 함수를 `C` 로 적어보도록 하겠습니다.

![](https://contents.codetree.ai/problems/21/images/introductions-64559ece-f9f4-4dc2-84ce-6aa8343686b9.png)

첫 번째 자리에 들어갈 수 있는 숫자는 0 혹은 1 이므로, `C(1, 0)` 이라는 함수는 0또는 1을 선택해줘야 합니다. 선택을 진행한 뒤에는 이제 두 번째 자리를 정해야 하므로 `C(2, 0)` 혹은 C(2, 1)을 호출해줍니다. 0을 고른 경우라면 1의 개수가 여전히 0개 이므로 `C(2, 0)` 을, 1을 고른 경우라면 1의 개수가 1개가 되었으므로 C(2, 1)을 호출합니다.

![](https://contents.codetree.ai/problems/21/images/introductions-2e4c2f36-08c3-49eb-b320-59e848f0bb72.png)

이런 과정에 따라 진행합니다. 종료조건은 curr\_num이 n + 1인 경우로 걸어주고, 그 당시에 지금까지 선택한 1의 개수인 cnt가 m인 경우에만 해당 숫자를 출력해주면 됩니다. 아례 예시에서는 n = 3, m = 2 입니다.

이러한 과정을 거쳐 재귀적으로 탐색을 진행하면 원하는 숫자들을 전부 만들어낼 수 있게 됩니다.

먼저 `choose(curr_num, cnt)` 함수를 정의합니다. 함수는 크게 종료 조건과, 재귀 함수 호출 코드로 구분되어져 있습니다.

먼저 재귀 함수 호출 부분의 코드를 살펴보겠습니다.  
현재 curr\_num 자리에 0을 넣는 경우에는 리스트의 가장 끝에 숫자 0을 적어주고, 그 다음 자릿수인 curr\_num + 1에 해당하는 함수 `choose(curr_num + 1, cnt)` 를 호출해 줍니다. 그 이후에 함수를 빠져나온 경우를 생각해, 리스트의 가장 끝에 적혀있는 숫자를 비워주는 코드를 작성해줍니다.  
curr\_num 자리에 1을 넣는 경우 역시 비슷하게 처리가 가능합니다. 1의 개수가 1 증가하므로 `choose(curr_num + 1, cnt + 1)` 을 호출해야 함에 유의합니다.

종료 조건은 `curr_num == n + 1` 조건을 만족하는 경우입니다. 이때 cnt가 m인 경우에만 리스트에 적혀있는 값들을 출력하면 됩니다.

따라서 출력해야 하는 1의 개수가 정해진 경우에는, 다음과 같이 1의 개수를 나타내는 인자를 추가하여 코드를 작성해볼 수 있습니다.

```python
n, m = 3, 2
answer = []

def choose(curr_num, cnt):
    if curr_num == n + 1:
        if cnt == m:
            print_answer()
        return

    answer.append(0)
    choose(curr_num + 1, cnt)
    answer.pop()

    answer.append(1)
    choose(curr_num + 1, cnt + 1)
    answer.pop()

    return
```
