Lesson 5. 격자 안에서 여러 객체를 이동

기본 문제에서는 단계별 학습을 위해 각 문제가 하나의 기본개념과 짝을 이룹니다. 연습 문제와 테스트 문제에서는 쉽게 복습할 수 있도록 모든 개념이 함께 제공됩니다.

## 격자 안에서 여러 객체를 이동

2차원 격자 위에서 여러 객체를 이동하는 유형에 대해 배워보도록 하겠습니다.

먼저 다음 문제를 살펴보겠습니다.

```
2차원 격자 정보가 주어졌을 때, m개 구슬을 동시에 
인접한 4개의 칸 중 현재 위치에 있는 숫자보다 더 큰 숫자로 동시에 
이동하는 것을 t번 반복하려고 합니다.

단, 인접한 4개의 칸 중 이동할 수 있는 위치가 여러 개 있는 경우, 
상하좌우 순서대로 우선순위를 매겨 가능한 곳 중 우선순위가 더 높은곳으로 이동하며, 
이동할 수 있는 위치가 없는 경우에는 움직이지 않습니다.

또, 이동 후 2개 이상의 구슬이 같은 칸에 오게 되면 
충돌이 생겨 해당 칸에 있는 모든 구슬은 사라지게 되며,
이동하는 도중에는 구슬끼리 서로 충돌하지 않는다고 가정합니다.

t번 구슬들을 동시에 움직이는 것을 반복한 이후에
최종적으로 남아있는 구슬의 수를 구해보세요.
```

아래 그림을 예로 보면 처음 구슬이 `(2, 1), (2, 4), (3, 3)` 위치에 놓여있으며, t = 1이므로 총 1번 이동하게 됩니다.

`(2, 1)` 구슬의 경우 상하좌우 순서대로 보다가 최초로 자신보다 커지는 순간이 오른쪽을 보는 순간이므로, `(2, 2)` 위치로 이동하게 됩니다.  
`(2, 4)` 구슬의 경우 상하좌우 순서대로 보다가 최초로 자신보다 커지는 순간이 왼쪽을 보는 순간이므로, `(2, 3)` 위치로 이동하게 됩니다.  
`(3, 3)` 구슬의 경우 상하좌우 순서대로 보다가 최초로 자신보다 커지는 순간이 위쪽을 보는 순간이므로, `(2, 3)` 위치로 이동하게 됩니다. 따라서 (2, 3) 위치에 두 구슬이 만나게 되므로 충돌이 생겨 사라지게 되며, 1번 이동을 진행한 이후에 남게 되는 구슬의 수는 1개가 됩니다.

![](https://contents.codetree.ai/problems/95/images/introductions-02d40a21-59d9-4ad9-b462-bd1409b1177d.png)

먼저 격자에서 인접한 4방향으로 이동하는 문제에서는 코드를 깔끔하게 작성하기 위해 dx, dy 테크닉을 이용하는 것이 좋습니다. dx, dy 테크닉에 대해 아직 잘 모르신다면, Novice Mid 문제집의 [dx, dy 테크닉](https://www.codetree.ai/missions/5/concepts/45/problems/move-in-direction/introduction) 유형을 공부하시고 나서 이 글을 읽는 것을 추천드립니다. 또, 이 문제에서는 상하좌우 순서대로 보다가 현재 위치보다 큰 경우 바로 이동해야 하므로, dx, dy 순서를 상하좌우 순서대로 적어주는 것이 좋습니다.

2차원 격자에서 여러 객체를 동시에 이동하는 유형의 문제들은 각 객체가 어느 위치에 있는지를 잘 관리하는 중요합니다. 1차원 리스트를 만들어 각 객체의 위치를 관리하는 식으로 진행할 수도 있지만, 일반적으로는 2차원 격자 상에서 각 칸 단위로 객체를 관리하는 것이 더 좋습니다.

이 문제의 경우 충돌 이후에는 각 위치에 많아야 최대 1개의 구슬이 남게되므로 격자마다 특정 위치에 구슬이 있는지만 표시해줘도 됩니다. 따라서 `count` 라는 2차원 배열을 만들어, 각 칸에 구슬이 있으면 1 없다면 0을 표기해줍니다.

![](https://contents.codetree.ai/problems/95/images/introductions-c51b54d3-00b2-41e0-b4ac-585188f81ee2.png)

이제 구슬을 전부 한 번씩 움직여봅니다. 이때, 한 번 움직인 이후 각 칸에 오게되는 구슬의 수를 담기 위해서 Next Count라는 배열을 활용합니다. 기존 count 배열을 그대로 이용하면 이전 구슬과 움직인 이후의 구슬을 구분할 수 없어서 같은 구슬을 두 번 움직이게 될 수도 있기 때문에, **이렇게 동시에 변화가 일어나야 하는 경우에는 새로운 배열을 만들어 주는 것이 항상 좋습니다.**

1번의 턴 동안 구슬이 움직이는 과정을 상세하게 적어보면 다음과 같습니다.

- **Step 2. 격자 내 칸들을 보면서 그 중 구슬이 있는 경우, Next Count 내 해당 구슬의 그 다음 위치에 1을 증가시킵니다.**

- **Step 3. Next Count 값을 다시 Count 배열에 복사합니다.**
	Next Count 값을 Count에 옮겨, 그 다음 턴에 Count 배열을 다시 사용할 수 있도록 합니다.
	![](https://contents.codetree.ai/problems/95/images/introductions-f25c40eb-79be-433d-b3cd-c09ba4d0f58b.png)
- **Step 4. 움직임 이후 충돌이 일어난 구슬들을 목록에서 지워줍니다.**
	이 과정은, 적혀있는 숫자가 2 이상인 칸들을 전부 0으로 바꿔주면 됩니다.
	![](https://contents.codetree.ai/problems/95/images/introductions-0312565f-ee6e-4828-a045-4b780692e0ca.png)
