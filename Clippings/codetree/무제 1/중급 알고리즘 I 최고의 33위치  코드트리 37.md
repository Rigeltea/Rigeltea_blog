Lesson 4. 아이템을 적절히 고르는 문제

## 최대 합 분할

Hard

90XP

평균 180분

52% 정답률

총 제출 546회

$N$ 개의 수가 주어졌을 때 이를 정확히 $3$ 개의 그룹 $A$, $B$, $C$ 로 나누어 $A$ 에 들어있는 수들의 합과 $B$ 에 들어있는 수들의 합이 같아지게 만들되, 그 합이 최대가 되도록 하는 프로그램을 작성해보세요. 단, 주어진 $N$ 개의 수는 각각 $A$, $B$ 또는 $C$ 중 정확히 한 곳에만 속해야 하며, 아무런 수도 포함하고 있지 않은 그룹 내 수들의 합은 $0$ 으로 정의됨에 유의합니다.

### 입력

첫 번째 줄에는 $N$ 이 주어집니다.

두 번째 줄에는 $N$ 개의 수가 공백을 사이에 두고 주어집니다.

### 제한 조건

- $1 \le N \le 100$
- $1 \le \texttt{주어지는 수} \le 1\,000$

### 출력

그룹 $A$ 와 $B$ 의 공통 합의 최댓값을 출력합니다.

### 입력 예제

### 예제 1

입력

```
4
2 2 1 5
```

출력

```
5
```

예제 설명

접기

이 예제에서 $A$ = { $2$, $2$, $1$ }, $B$ = { $5$ }, $C$ = {} 이렇게 $3$ 개의 그룹으로 나뉘면 $A$, $B$ 그룹 내 수들의 합이 $5$ 로 동일하며 그 합이 최대가 됩니다.

### 예제 2

입력

```
5
4 7 8 9 5
```

출력

```
13
```

예제 설명

접기

이 예제에서 $A$ = { $4$, $9$ }, $B$ = { $8$, $5$ }, $C$ = { $7$ } 이렇게 $3$ 개의 그룹으로 나뉘면 $A$, $B$ 그룹 내 수들의 합이 각각 $13$ 으로 동일하며 그 합이 최대가 됩니다.

### 예제 3

입력

```
2
4 5
```

출력

```
0
```

예제 설명

접기

이 예제에서 $A$ = {}, $B$ = {}, $C$ = { $4$, $5$ } 이렇게 $3$ 개의 그룹으로 나뉘면 $A$, $B$ 그룹 내 수들의 합이 각각 $0$ 으로 동일하며 그 합이 최대가 됩니다.

### 제한

• Time Limit: 3000 ms

• Memory Limit: 512 MiB
