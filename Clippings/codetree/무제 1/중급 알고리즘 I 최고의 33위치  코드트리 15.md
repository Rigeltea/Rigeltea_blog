Lesson 4. 순열 만들기

## 수들 중 최솟값 최대화하기

Medium

90XP

평균 20분

76% 정답률

총 제출 1,019회

크기가 $N \times N$ 인 이차원 격자 내 각 칸에 정수값이 적혀 있습니다.

이때 정확히 $N$ 개의 칸에 색칠을 하여 각 행과 열에 정확히 $1$ 개의 색칠된 칸만 오도록 하려고 합니다. 이러한 조건 하에서 색칠된 칸에 적힌 수들 중 최솟값이 최대가 되도록 하는 프로그램을 작성해보세요.

### 입력

첫 번째 줄에 $N$ 이 주어집니다.

두 번째 줄부터 $N$ 개의 줄에 걸쳐 한 줄에 $N$ 개씩의 정수가 공백을 두고 주어집니다.

### 제한 조건

- $1 \le N \le 10$
- $1 \le \texttt{주어지는 정수} \le 10\,000$

### 출력

조건을 만족하는 경우 중 색칠된 칸에 적힌 수들의 최솟값이 될 수 있는 값들 중 최대를 출력합니다.

### 입력 예제

### 예제 1

입력

```
3
3 5 3
5 8 4
2 7 1
```

출력

```
3
```

예제 설명

접기

$(1,\ 3)$, $(2,\ 2)$, $(3,\ 1)$ 에 색칠을 했다면 선택된 수들 중 최솟값은 $2$ ($3$, $8$, $2$ 중 최소)가 됩니다.  
하지만 $(1,\ 3)$, $(2,\ 1)$, $(3,\ 2)$ 에 색칠을 했다면 선택된 수들 중 최솟값은 $3$ ($3$, $5$, $7$ 중 최소)으로 최대가 됩니다.

### 제한

• Time Limit: 4000 ms

• Memory Limit: 128 MiB
