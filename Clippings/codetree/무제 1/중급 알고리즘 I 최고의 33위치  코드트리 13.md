Lesson 3. N개 중에 M개 고르기(Simple)

## N개의 점 중 M개 고르기

Medium

70XP

평균 69분

48% 정답률

총 제출 2,018회

좌표 평면 위에 점 $N$ 개의 좌표가 주어졌을 때, 점 $M$ 개를 적절히 선택하여 선택한 점들 중 거리가 가장 먼 두 점 사이의 거리값이 최소가 되도록 하는 프로그램을 작성해주세요.  
단 여기서의 거리란 유클리디안 거리를 뜻합니다. 두 점 $(x_1,\ y_1), (x_2,\ y_2)$ 사이의 유클리디안 거리 $dist$ 는 다음과 같이 정의됩니다.

$$
dist = \sqrt{(x_1-x_2)^2 + (y_1 - y_2)^2}
$$

### 입력

첫 번째 줄에는 정수 $N$ 과 $M$ 이 공백을 사이에 두고 주어집니다.

두 번째 줄부터는 $N$ 개의 줄에 걸쳐 점의 좌표 $x_i$, $y_i$ 가 공백으로 구분되어 주어집니다. 이는 $i$ 번째 점의 좌표가 $(x_i,\ y_i)$ 임을 의미합니다.

### 제한 조건

- $2 \le M \le N \le 20$
- $1 \le x_i,\ y_i \le 100$ $(1 \le i \le N)$
- 주어지는 모든 점의 위치는 서로 다릅니다.

### 출력

점 $M$ 개를 적절히 선택하여 가장 먼 두 점 사이의 거리가 최소가 되었을 때, 그때의 최소 거리에 제곱한 값을 출력합니다.

### 입력 예제

### 예제 1

입력

```
2 2
1 1
1 3
```

출력

```
4
```

### 예제 2

입력

```
3 2
1 1
4 4
3 5
```

출력

```
2
```

예제 설명

접기

$2$, $3$ 번 점을 선택했을 때 거리가 최소가 됩니다.

### 제한

• Time Limit: 1000 ms

• Memory Limit: 128 MiB
