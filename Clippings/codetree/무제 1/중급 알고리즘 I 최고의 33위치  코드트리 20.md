Lesson 1. BFS 탐색

기본 문제에서는 단계별 학습을 위해 각 문제가 하나의 기본개념과 짝을 이룹니다. 연습 문제와 테스트 문제에서는 쉽게 복습할 수 있도록 모든 개념이 함께 제공됩니다.

## BFS 탐색

BFS역시 그래프 상에서 정의됩니다. 그래프에서의 탐색은 크게 DFS, BFS 이렇게 2개가 있습니다.

BFS는 시작점을 기준으로 가장 가까운 곳부터 순서대로 탐색을 진행하는 방식으로 **너비 우선 탐색** 이라 불립니다.

## 그래프에서의 BFS 탐색

먼저 그래프에서 BFS 탐색은 어떻게 진행되는지에 대해 알아보려고 합니다. 다음과 같이 그래프가 주어졌을 때, 1번 정점에서 시작하여 BFS 탐색을 하는 코드를 예로 진행해보겠습니다. 단, 갈 수 있는 정점이 여러 개라면 번호가 작은 정점부터 방문해보겠습니다. 아래 그래프에서 BFS 방문 순서는 1, 2, 3, 4, 5, 6, 7이 됩니다.

![](https://contents.codetree.ai/problems/33/images/introductions-a27458af-be73-4404-aee2-2749a591c60a.png)

먼저 인접 행렬을 이용해서 구현해보겠습니다. graph라는 이름의 2차원 배열을 만들어, 두 정점이 연결되어 있다면 1 아니라면 0으로 표시해 줍니다.

![](https://contents.codetree.ai/problems/33/images/introductions-0ae48406-d1f3-4b83-9955-87a3ef718d5a.png)

이후 BFS 탐색을 진행합니다. BFS는 **꼭 재귀함수 없이 queue** 라는 자료구조를 이용하여 작성합니다. 아직 queue에 대해 잘 모르신다면, Novice High 문제집의 [Queue 자료구조](https://www.codetree.ai/missions/6/concepts/32/problems/queue-basic/introduction) 를 공부하시고나서 이 글을 읽는 것을 추천드립니다.

![Image](https://contents.codetree.ai/problem_factory/images/b3ea38aa-d977-4df1-8238-29a402df886c.webp)

DFS는 새로 방문하게 되는 위치가 생기면 해당 위치를 DFS함수의 인자로 넘기며 재귀함수를 호출해 탐색을 재개합니다. 하지만, BFS는 queue를 이용해 지금까지 방문한 노드들을 관리합니다. 새로 방문하게 되는 노드를 queue에 계속 넣어주며, queue가 empty 상태가 되기 전까지 queue에서 가장 앞에 있는 원소를 pop하여 해당 원소를 현재 원소의 위치로 설정합니다. 이 위치를 기준으로 연결된 지점들에 대한 탐색을 진행하게 되는 것입니다.

![Image](https://contents.codetree.ai/problem_factory/images/193bb645-97c7-4bfe-816a-c1cfc1246390.webp)

BFS에서는 queue에서 뽑힌 위치 curr\_v가 현재 위치가 됩니다. 이 현재 위치를 기준으로 연결된 정점을 탐색하기 위해서는 1번부터 정점의 개수인 VERTICES\_NUM까지 포문을 돌아야 합니다. 이 지점을 next\_v라 했을 때, `graph[curr_v][next_v]` 값이 1이면서 **next\_v 정점** 에 방문했던 적이 없는 지를 확인해야 합니다. 다음 예시에서는 1번 정점에 연결된 정점들이 2, 3, 4 이므로, next\_v 값이 2, 3, 4 인 경우에만 if 조건을 만족하게 됩니다. 이 과정은 DFS에서의 과정과 동일합니다.

![Image](https://contents.codetree.ai/problem_factory/images/56ba58f1-77db-41b8-8e50-b131a252e627.webp)

위 코드에서 `visited` 란 무엇일까요? 이는 방문했던 정점을 다시는 방문하지 않도록 하는 역할을 합니다.

이를 이해하기 위해서는 그래프 탐색 알고리즘의 2가지 대원칙을 꼭 기억하셔야 합니다.

1. 시작점으로부터 연결된 모든 정점을 전부 방문해야 합니다.
2. 이미 방문한 정점은 다시는 방문하지 않습니다.

만약 이미 방문한 정점을 다시 방문할 수 있도록 한다면, 1번 정점에서 시작하여 2번 정점으로 갔다가, 다시 2번 정점은 1번 정점과 연결되어 있으므로 1번 정점으로 오며 1, 2를 계속 왔다갔다 하는 것을 반복하게 될 것입니다.

따라서 다음과 같이 정점의 개수만큼의 크기를 갖는 visited 배열을 만들어 **queue에 새로운 위치를 넣어주는 순간에 꼭 해당 위치의 visited 값을 true** 로 변경하여, 다시는 탐색 도중에 해당 위치에 방문하지 않도록 해야만 합니다.

![Image](https://contents.codetree.ai/problem_factory/images/453a51b7-b383-4574-8dd3-90b4535f0bd1.webp)

이렇게 1번 정점에서 시작하여 연결되어 있으며 아직 방문해본 적이 없는 정점이 발견되면 visited 값을 true로 변경한 뒤 계속 탐색을 진행하게 됩니다. 이를 전체 코드와 함께 보면 다음과 같습니다.

![](https://contents.codetree.ai/problems/33/images/introductions-68fd61b3-71f8-4a20-b2df-945fa832d515.png)

이후 BFS 탐색을 진행합니다. 인접 행렬을 이용하는 경우와 마찬가지로 queue를 이용하게 되지만, 이때 연결된 정점을 찾아내는 방법만 조금 다릅니다. 현재 위치를 vertex라 했을 때, 인접리스트에서는 연결된 정점이 전부 **`graph[vertex]`** 안에 리스트 형태로 들어있게 됩니다.

![](https://contents.codetree.ai/problems/33/images/introductions-b068c8ce-8d51-4271-b065-37e8c2abef6a.png)

따라서 \*\* `graph[vertex]` \*\*에 들어있는 원소들을 순서대로 순회하면 해당 원소는(curr\_v라 부르겠습니다) 그 즉시 vertex에 연결되어 있는 원소가 됩니다.

![](https://contents.codetree.ai/problems/33/images/introductions-b30f1dba-936c-4947-aed9-3e7072218fd1.png)

따라서 `visited[curr_v]` 값이 false인지만 확인하여 방문되지 않은 정점에 대해서만 다음 탐색을 진행해주면 됩니다.

## 격자에서의 BFS 탐색

다음과 같이 2차원 격자가 주어져 있는 상황에서 특정 시작점으로 부터 갈 수 있는 모든 지점을 방문하는 BFS 탐색은 어떻게 구현해 볼 수 있을까요? 단, 좌측 상단에서 시작하여 인접한 칸들 중 아래, 오른쪽으로만 이동할 수 있으며, 뱀이 있는 위치로는 이동할 수 없습니다. 두 방향 모두 이동이 가능할 경우 아래쪽을 우선적으로 탐색한다고 했을 때, 각 위치의 방문 순서를 적어보려고 합니다. 그 예시는 다음과 같습니다.

![](https://contents.codetree.ai/problems/33/images/introductions-246888e1-4f3f-4eb0-a93c-c26c32c6273c.png)

일반적인 그래프에서 두 정점의 연결관계를 표현하기 위해서는 인접 행렬 혹은 인접 리스트를 꼭 이용해야 한다고 배웠습니다. 하지만 2차원 격자에서는 보통 인접한 곳으로만 이동이 가능하므로, 현재 위치 (x, y)를 기준으로 (x + 1, y), (x - 1, y), (x, y + 1), (x, y - 1) 중 한 곳으로 이동하게 될 수 밖에 없습니다. 즉, 격자 문제에서는 굳이 그래프를 표현하기 위한 인접 행렬 혹은 인접 리스트를 만들어줄 필요가 없습니다.

![](https://contents.codetree.ai/problems/33/images/introductions-d9176a38-e669-4fbb-82e9-be4ee90e65eb.png)

그래프에서의 BFS 탐색에서는 queue가 필요하며, queue에 각 노드의 위치를 넣어야 한다고 했었습니다. 격자에서의 BFS 탐색에서 현재 위치를 표현하기 위해서는 (x, y) 이렇게 2개의 값이 꼭 필요합니다. **여기서 (x, y)는 수학에서의 x, y가 아닌 행렬에서의 (i, j)와 같이 x행, y열을 의미함에 꼭 유의합니다.**

이 때문에 자연스럽게도 visited 배열 역시 2차원이 되어야 합니다. 0번지부터 사용한다고 했을 때 시작 위치는 (0, 0)이므로, 다음과 같은 개형으로 시작해볼 수 있습니다. visit 체크를 하고, queue에 원소를 넣는 과정을 진행하는 함수 `push` 를 새로 정의하여 이용하면 보다 깔끔하게 코드를 작성해볼 수 있습니다.

![](https://contents.codetree.ai/problems/33/images/introductions-45fd7a6d-d577-4ee4-b436-4ee193951da8.png)

BFS는 queue가 empty 상태가 되기 전까지 계속 탐색을 반복합니다. DFS는 함수의 인자 값으로 현재 위치를 반환해주지만, BFS는 현재 queue에서 가장 앞에 있는 원소를 현재 위치로 설정해줘야 합니다. 이때 꼭 queue에서 해당 원소를 pop 해줘야만 함에 유의합니다.

![](https://contents.codetree.ai/problems/33/images/introductions-b6b399a9-e64e-4518-9a62-5b20b62e3a0a.png)

현재 위치 (x, y)가 정해졌다면, 이 위치로부터 갈 수 있는 곳들을 전부 탐색하여 그 중 **갈 수 있는 곳** 이 있다면, 해당 위치에 방문 체크를 해준 뒤 해당 위치를 queue에 넣어주는 식으로 구현이 되어야 합니다. 이때 이 문제에서는 인접한 칸들 중 우측 혹은 아래 방향으로만 이동할 수 있으므로 다음과 같이 dx, dy 테크닉을 이용하여 new\_x, new\_y에 인접한 칸의 위치가 오도록 설정해줄 수 있습니다. 만약 아직 dx, dy 테크닉에 대해 잘 모르신다면, Novice Mid 문제집의 [dx, dy 테크닉 유형](https://www.codetree.ai/missions/5/concepts/45/problems/move-in-direction/introduction) 을 공부하시고 나서 이 글을 읽는 것을 추천드립니다.

![](https://contents.codetree.ai/problems/33/images/introductions-bf434b1e-6271-42ea-9b64-ab7dd6ff431d.png)

인접한 위치 (new\_x, new\_y)로 이동해야 할 필요가 있다면, visited 값을 true로 설정해주고 queue에 해당 위치를 넣어주면 됩니다.

![](https://contents.codetree.ai/problems/33/images/introductions-56615e02-225b-4d53-8688-dcb6920525fe.png)

이때 (new\_x, new\_y)로 이동해도 되는지를 판단해주는 함수를 편의상 `CanGo` 라고 작성해봤습니다. (new\_x, new\_y)로 이동이 가능하기 위해서는 다음 3가지의 조건을 만족해야 합니다.

```
1. (new_x, new_y)가 격자 안에 있어야 합니다.
2. (new_x, new_y)에 방문한 적이 없어야 합니다.
3. (new_x, new_y)에 뱀이 없어야 합니다.
```

이 3가지 조건을 다 만족하는지를 판단하는 함수 CanGo를 만들고, 이 조건을 만족하는 경우에만 새로 queue에 넣어주면 됩니다. 이때 격자 내에 있는지를 판단하는 함수 역시 InRange라는 이름으로 새로 만들어 관리해주면 가독성을 높일 수 있습니다.

![](https://contents.codetree.ai/problems/33/images/introductions-db267d93-d334-4180-b2bd-39839fb5db61.png)
