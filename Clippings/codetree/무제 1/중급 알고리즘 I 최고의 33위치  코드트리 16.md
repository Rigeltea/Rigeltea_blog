Lesson 1. DFS

기본 문제에서는 단계별 학습을 위해 각 문제가 하나의 기본개념과 짝을 이룹니다. 연습 문제와 테스트 문제에서는 쉽게 복습할 수 있도록 모든 개념이 함께 제공됩니다.

## 그래프 상에서의 DFS 탐색

먼저 DFS는 그래프 상에서 정의됩니다. 그래프란 정점과 간선으로 이루어져 있는 자료구조로, 정점간의 연결 관계가 간선을 이용하여 표현됩니다. 그래프에 대해 아직 잘 모르신다면, Novice High 문제집의 [그래프 유형](https://www.codetree.ai/missions/6/concepts/36/problems/graph-concept/introduction) 을 공부하시고 나서 이 글을 읽는 것을 추천드립니다.

![](https://contents.codetree.ai/problems/53/images/introductions-d6e798ff-9e71-4319-9221-885efd9b7ea0.png)

그래프를 인접 행렬 혹은 인접 리스트로 나타낼 수 있습니다. 그래프를 코드로 구현하는 부분에 대해 아직 잘 모르신다면, Novice High 문제집의 [그래프 구현 유형](https://www.codetree.ai/missions/6/concepts/36/problems/graph-using-adjust-graph/introduction) 을 공부하시고 나서 이 글을 읽는 것을 추천드립니다.

**인접 행렬** 을 이용한다면, 두 정점 i, j가 연결관계에 있다면 `graph[i][j]` 값을 1로, 그렇지 않다면 `graph[i][j]` 값을 0으로 정의하여 표현합니다. 그 예시는 다음과 같습니다.

양방향 그래프라면 인접 행렬이 대칭인 모양이 되며, 단방향 그래프라면 그렇지 않을 것입니다. 그래프에서 정점의 수를 V, 간선의 수를 E라 했을 때 인접 행렬 이용시 공간복잡도는 $O(V^2)$ 이 됩니다.

**인접 리스트** 를 이용한다면, **V개의 동적 배열** 을 만들어 관리해야 합니다. i번째 정점에 해당하는 동적 배열을 `graph[i]` 라 한다면, `graph[i]` 에 해당하는 동적 배열에 정점 i에 연결된 모든 정점 번호가 들어가야 합니다. 그 예시는 다음과 같습니다.

인접 리스트의 경우 V개의 동적배열을 관리하는 리스트 1개와, 각 간선별로 정점이 2개씩 동적 배열에 각각 추가되므로 공간복잡도는 $O(V+E)$ 가 됩니다.

DFS는 특정 정점에서 시작하여 갈 수 있는 곳까지 쭉 따라 들어갔다가 더 이상 갈 곳이 없으면 빠져나오는 방식의 그래프 탐색 방법으로 **깊이 우선 탐색** 이라 불립니다.

아직 DFS 개념에 대해 잘 모르신다면, Novice High 문제집의 [DFS 탐색 유형](https://www.codetree.ai/missions/6/concepts/36/problems/dfs-code/introduction) 을 공부하시고나서 이 글을 읽는 것을 추천드립니다.

이제 다음과 같이 그래프가 주어졌을 때, 1번 정점에서 시작하여 DFS 탐색을 하는 코드를 작성해보려고 합니다. 단, 갈 수 있는 정점이 여러 개라면 번호가 작은 정점부터 방문해보겠습니다. 아래 그래프에서 DFS 방문 순서는 1, 2, 5, 3, 4, 6, 7이 됩니다.

![](https://contents.codetree.ai/problems/53/images/introductions-1b2e9efe-d338-460e-995f-8a70a7aedf03.png)

먼저 **인접 행렬** 을 이용해서 구현해보겠습니다. graph라는 이름의 2차원 배열을 만들어, 두 정점이 연결되어 있다면 1 아니라면 0으로 표시해 줍니다.

![](https://contents.codetree.ai/problems/53/images/introductions-8c3c267e-c192-40fc-a0e7-231819712348.png)

이후 DFS 탐색을 진행합니다. DFS는 **꼭 재귀함수** 를 이용하여 작성합니다.

![](https://contents.codetree.ai/problems/53/images/introductions-db27091b-a1e5-449b-b1fc-79c2feb0912b.png)

DFS 함수에서 첫 번째 인자인 vertex는 현재 위치를 의미합니다. 이 현재 위치를 기준으로 연결된 정점을 탐색하기 위해서는 1번부터 정점의 개수인 VERTICES\_NUM까지 포문을 돌아야 합니다. 이 지점을 curr\_v라 했을 때, `graph[vertex][curr_v]` 값이 1이면서 **curr\_v 정점** 에 방문했던 적이 없는 지를 확인해야 합니다. 다음 예시에서는 1번 정점에 연결된 정점들이 2, 3, 4 이므로, curr\_v 값이 2, 3, 4 인 경우에만 if 조건을 만족하게 됩니다.

![](https://contents.codetree.ai/problems/53/images/introductions-a547eda6-1c32-4351-9d26-557bf63c8340.png)

위 코드에서 `visited` 란 무엇일까요? 이는 방문했던 정점을 다시는 방문하지 않도록 하는 역할을 합니다.

이를 이해하기 위해서는 그래프 탐색 알고리즘의 2가지 대원칙을 꼭 기억하셔야 합니다.

1. 시작점으로부터 연결된 모든 정점을 전부 방문해야 합니다.
2. 이미 방문한 정점은 다시는 방문하지 않습니다.

만약 이미 방문한 정점을 다시 방문할 수 있도록 한다면, 1번 정점에서 시작하여 2번 정점으로 갔다가, 다시 2번 정점은 1번 정점과 연결되어 있으므로 1번 정점으로 오며 1, 2를 계속 왔다갔다 하는 것을 반복하게 될 것입니다.

따라서 다음과 같이 정점의 개수만큼의 크기를 갖는 visited 배열을 만들어 **그 다음 DFS 함수를 호출하기 전에 꼭 해당 위치의 visited 값을 true** 로 변경하여, 다시는 탐색 도중에 해당 위치에 방문하지 않도록 해야만 합니다.

![](https://contents.codetree.ai/problems/53/images/introductions-a66ac980-3837-4e9d-bf3d-4c91792a135e.png)

이렇게 1번 정점에서 시작하여 연결되어 있으며 아직 방문해본 적이 없는 정점이 발견되면 visited 값을 true로 변경한 뒤, 다시 재귀적으로 해당 위치로 DFS 함수를 호출하는 것을 반복하면 됩니다.

이제는 **인접 리스트** 를 이용해서 DFS를 구현해보겠습니다. 먼저 graph라는 이름의 1차원 배열을 만들고, `graph[i]` 는 각각 i번째 정점에 연결되어 있는 정점들 목록을 관리하는 동적배열이 되어야 합니다.

![](https://contents.codetree.ai/problems/53/images/introductions-f1d3b179-72bb-4e69-a40f-a5be0d0225c1.png)

이후 DFS 탐색을 진행합니다. 인접 행렬을 이용하는 경우와 마찬가지로 재귀함수를 작성해야 하는데, 이때 연결된 정점을 찾아내는 방법만 조금 다릅니다. 현재 위치를 vertex라 했을 때, 인접리스트에서는 연결된 정점이 전부 **`graph[vertex]`** 안에 리스트 형태로 들어있게 됩니다.

![](https://contents.codetree.ai/problems/53/images/introductions-1eb27bf4-f23a-40ab-bee0-086a5abc13c1.png)

따라서 **`graph[vertex]`** 에 들어있는 원소들을 순서대로 순회하면 해당 원소는(curr\_v라 부르겠습니다) 그 즉시 vertex에 연결되어 있는 원소가 됩니다.

![](https://contents.codetree.ai/problems/53/images/introductions-1237bb5e-1f38-4de7-b61b-f79a37628e3d.png)

`visited[curr_v]` 값이 false인지만 확인하여 방문되지 않은 정점에 대해서만 다음 탐색을 진행해주면 됩니다.

![](https://contents.codetree.ai/problems/53/images/introductions-af7781b2-4d08-4655-a512-6741ec2eb474.png)

이렇게 1번 정점에서 시작하여 연결되어 있으며 아직 방문해본 적이 없는 정점이 발견되면 visited 값을 true로 변경한 뒤, 다시 재귀적으로 해당 위치로 DFS 함수를 호출하는 것을 반복하면 됩니다.
