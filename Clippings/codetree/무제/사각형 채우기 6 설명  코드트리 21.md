Lesson 3. Deque

기본 문제에서는 단계별 학습을 위해 각 문제가 하나의 기본개념과 짝을 이룹니다. 연습 문제와 테스트 문제에서는 쉽게 복습할 수 있도록 모든 개념이 함께 제공됩니다.

## 덱 사용

python에서는 deque라는 package가 있습니다. deque는 collections라는 모듈에 있으며, 사용을 위해서는 `from collections import deque` 를 가장 위에 적어줘야 합니다.

다만, python에 있는 deque의 경우 각 함수의 용어가 앞에서 다뤘던 `push_front` 같은 형식이 아닙니다. 따라서 각 함수의 역할에 대해 잘 이해하고 있어야만 합니다.

deque를 이용할 때 자주 사용되는 것은 다음 8가지 입니다.

`dq = deque()` 로 정의가 되어있다는 가정하에, 다음과 같이 이용해볼 수 있습니다.

1. `dq.appendleft(E)`

맨 앞에 데이터 E를 추가합니다.

2. `dq.append(E)`

맨 뒤에 데이터 E를 추가합니다.

3. `dq.popleft()`

맨 앞에 있는 데이터를 제거하며, 해당 원소의 값을 반환합니다.

4. `dq.pop()`

맨 뒤에 있는 데이터를 제거하며, 해당 원소의 값을 반환합니다.

5. `len(dq)`

현재 deque에 들어있는 데이터의 수를 반환하기 위해서는 list내 원소의 길이를 구했을 때 처럼 `len()` 함수를 이용해야 합니다.

6. `if dq`

현재 deque가 비어있지 않은지를 확인하기 위해서는 `if dq` 형태로 적어주면 됩니다.  
반대로 deque가 비어있는지가 궁금하다면, `if not dq` 형태로 적어주면 됩니다.

7. `dq[0]`

deque의 맨 앞에 있는 데이터를 반환하기 위해서는, list내의 첫 번째 원소를 참조하듯이 0번째 index 값을 참조하면 됩니다.

8. `dq[-1]`

deque의 맨 뒤에 있는 데이터를 반환하기 위해서는, list내의 마지막 원소를 참조하듯이 -1번째 index 값을 참조하면 됩니다.

따라서 다음과 같이 코드를 작성해볼 수 있습니다.

```python
from collections import deque

dq = deque()        # 정수를 관리할 deque를 선언합니다. => 빈 덱
dq.appendleft(3)    # 맨 앞에 3을 추가합니다.
dq.appendleft(5)    # 맨 앞에 5를 추가합니다.
print(dq[0])        # 맨 앞에 적혀있는 숫자인 5가 출력됩니다.
print(dq[-1])       # 맨 뒤에 적혀있는 숫자인 3이 출력됩니다.
dq.append(9)        # 맨 뒤에 9를 추가합니다.
print(dq[-1])       # 맨 뒤에 적혀있는 숫자인 9가 출력됩니다.
dq.popleft()        # 맨 앞 숫자(5)를 제거합니다.
print(dq[0])        # 맨 앞에 적혀있는 숫자인 3이 출력됩니다.
print(len(dq))      # 원소의 개수를 출력합니다 => 2
```
