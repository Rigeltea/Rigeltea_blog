남우는 이전에 피보나치 수열을 계산하는 재귀 함수에 메모이제이션을 적용한 경험을 바탕으로 파도반 수열에도 동일한 기법을 도입했습니다. 그러나 자신이 학습한 메모이제이션이 실제로 제대로 작동하는지 확인하고자 중간 과정을 출력하는 코드를 추가하여 검증해 보았습니다.

```js
memo = [-1, -1, -1, ...]

function padovan(n)
    if memo[n] != -1
        return memo[n]
    if n <= 3
        memo[n] = 1
    else
        memo[n] = padovan(n - 2) + padovan(n - 3)
        print(memo[n])

    return memo[n]
```

다음은 남우가 작성한 코드입니다. 처음에 `padovan(10)` 을 실행시키면 어떤 결과가 출력될까요?
