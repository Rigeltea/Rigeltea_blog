다익스트라 알고리즘의 코드를 다음과 같이 변경하였습니다.

```jsx
function dijkstra(graph, source)
  set Q = []
  
  for each vertex v in Graph:
    set dist[v] = INF
    add v to Q
    
  set dist[source] = 0
  
  while Q is not empty
    set u = vertex in Q with min dist[u]
    
    remove u from Q
      
    for each neighbor v of u
      set alt = dist[u] + length(u, v)
      if alt < dist[v]
        set dist[v] = alt
        
  return dist
```

일반적인 다익스트라 알고리즘의 구현과 다르게, $Q$ 가 우선순위 큐 대신 배열로 변경되었습니다. 이에 따라 최솟값을 찾는 방법이 다소 달라지게 됩니다.
