다음과 같이 Union-Find를 활용한 연산을 수행했습니다.

```jsx
function init(size)
  set uf = [0] with size
  for i = 1 ... size
    uf[i] = i
  return uf

function find(x)
  if uf[x] == x
    return x
  return find(uf[x])
  
function union(x, y)
  set X = find(x), Y = find(y)
  uf[X] = Y

uf = init(6)

union(2, 3)
union(1, 4)
union(1, 5)
union(4, 2)
union(3, 1)

print(find(1))
print(find(2))
print(find(3))
print(find(4))
print(find(5))
```
