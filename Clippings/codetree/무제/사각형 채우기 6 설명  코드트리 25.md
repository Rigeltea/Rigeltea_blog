Lesson 2. Lower/Upper Bound

## bound 코드

Medium

10XP

평균 5분

36% 정답률

총 제출 3,114회

다음과 같이 4개의 함수를 구현한 코드가 주어져 있습니다.

```jsx
function bound1(arr, target)
  set left = 0
  set right = arr.size - 1
  set min_idx = arr.size
  while left <= right
    set mid = (left + right) / 2
    if arr[mid] >= target
      right = mid - 1
      min_idx = min(min_idx, mid)
    else
      left = mid + 1

  return min_idx

function bound2(arr, target)
  set left = 0
  set right = arr.size - 1
  set min_idx = arr.size
  while left <= right
    set mid = (left + right) / 2
    if arr[mid] > target
      right = mid - 1
      min_idx = min(min_idx, mid)
    else
      left = mid + 1

  return min_idx

function bound3(arr, target)
  set left = 0
  set right = arr.size - 1
  set max_idx = -1
  while left <= right
    set mid = (left + right) / 2
    if arr[mid] <= target
      left = mid + 1
      max_idx = max(max_idx, mid)
    else
      right = mid - 1

  return max_idx

function bound4(arr, target)
  set left = 0
  set right = arr.size - 1
  set max_idx = -1
  while left <= right
    set mid = (left + right) / 2
    if arr[mid] < target
      left = mid + 1
      max_idx = max(max_idx, mid)
    else
      right = mid - 1

  return max_idx
```

다음 값들에 대해 `bound1`, `bound2`, `bound3`, `bound4` 의 반환 값들을 순서대로 골라보세요.

```jsx
arr = [8, 10, 12, 14, 14, 16, 16, 16, 18, 20, 22]
target = 16
```
