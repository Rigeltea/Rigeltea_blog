다음 빈칸을 채워 넣어 $n$ 번째 피보나치 수를 빠르게 구하는 코드를 완성해 봅시다.

```jsx
memo = [-1, -1, -1, ... ]

function fibbo(n)
    if (1) != -1
        return (2)
    if n <= 2
        (3) = 1
    else
        (4) = fibbo(n - 1) + fibbo(n - 2)

    return (5)
```
