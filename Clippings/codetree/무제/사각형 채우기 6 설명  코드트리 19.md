Lesson 2. Queue

기본 문제에서는 단계별 학습을 위해 각 문제가 하나의 기본개념과 짝을 이룹니다. 연습 문제와 테스트 문제에서는 쉽게 복습할 수 있도록 모든 개념이 함께 제공됩니다.

## 큐 사용

python에 queue라는 class가 있기는 하지만 이는 알고리즘 문제를 풀기 위해 나온 class가 아니라 thread간의 synchronized를 맞춰야 하는 제약이 있는 class이기 때문에 사용시 속도가 굉장히 느려집니다. **따라서 python에서 제공하는 deque를 사용해 queue를 대신하여 이용하고는 합니다.** deque는 collections라는 모듈에 있으며, 사용을 위해서는 `from collections import deque` 를 가장 위에 적어줘야 합니다. 단, 사용의 편의를 위해 Queue라는 class를 직접 만들어 deque를 이용해 클래스 내 함수를 정의한 뒤, 정의된 Queue 클래스를 이용해 보겠습니다.

```python
from collections import deque

class Queue:
    def __init__(self):          # 빈 큐 하나를 생성합니다.
        self.dq = deque()
                
    def push(self, item):        # 큐의 맨 뒤에 데이터를 추가합니다.
        self.dq.append(item)
                
    def empty(self):             # 큐가 비어있으면 True를 반환합니다.
        return not self.dq
                
    def size(self):              # 큐에 들어있는 데이터 수를 반환합니다.
        return len(self.dq)
        
    def pop(self):               # 큐의 맨 앞에 있는 데이터를 반환하고 제거합니다.
        if self.empty():
            raise Exception("Queue is empty")
            
        return self.dq.popleft()
                
    def front(self):             # 큐의 맨 앞에 있는 데이터를 제거하지 않고 반환합니다.
        if self.empty():
            raise Exception("Queue is empty")
                        
        return self.dq[0]
```

queue를 이용할 때 자주 사용되는 것은 다음 5가지 입니다.

1. `push(E)`

맨 뒤에 데이터 E를 추가합니다.

2. `size()`

현재 queue에 들어있는 데이터의 수를 반환합니다.

3. `empty()`

현재 queue가 비어있다면 true, 아니라면 false를 반환합니다.

4. `front()`

queue의 맨 앞에 있는 데이터를 반환합니다.

5. `pop()`

queue의 맨 앞에 있는 데이터를 반환합니다. 동시에 그 데이터를 queue에서 뺍니다.

따라서 다음과 같이 코드를 작성해볼 수 있습니다.

```python
from collections import deque

class Queue:
    def __init__(self):          # 빈 큐 하나를 생성합니다.
        self.dq = deque()
                
    def push(self, item):        # 큐의 맨 뒤에 데이터를 추가합니다.
        self.dq.append(item)
                
    def empty(self):             # 큐가 비어있으면 True를 반환합니다.
        return not self.dq
                
    def size(self):              # 큐에 들어있는 데이터 수를 반환합니다.
        return len(self.dq)
        
    def pop(self):               # 큐의 맨 앞에 있는 데이터를 반환하고 제거합니다.
        if self.empty():
            raise Exception("Queue is empty")
            
        return self.dq.popleft()
                
    def front(self):             # 큐의 맨 앞에 있는 데이터를 제거하지 않고 반환합니다.
        if self.empty():
            raise Exception("Queue is empty")
                        
        return self.dq[0]

q = Queue()             # 정수를 관리할 queue를 선언합니다. => 빈 큐
q.push(3) 
q.push(5)
q.push(9)
    
print(q.front())        # 가장 앞에 있는 원소를 출력합니다. => 3
q.pop()                 # 가장 앞에 있는 원소를 제거합니다.
print(q.size())         # 원소의 개수를 출력합니다 => 2
while not q.empty():    # 가장 앞에 있는 원소부터 순서대로 출력합니다.
    print(q.front())    # 순서대로 5 9 출력됩니다.
    q.pop()             # 가장 앞에 있는 원소를 제거합니다.
```
