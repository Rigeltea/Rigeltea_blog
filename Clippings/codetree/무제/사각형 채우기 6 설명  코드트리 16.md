Lesson 2. Queue

기본 문제에서는 단계별 학습을 위해 각 문제가 하나의 기본개념과 짝을 이룹니다. 연습 문제와 테스트 문제에서는 쉽게 복습할 수 있도록 모든 개념이 함께 제공됩니다.

## 큐의 정의와 활용

유명 맛집에 갔다고 가정해봅시다. 대기줄이 너무 길지만, 오늘 아니면 못 먹을 것 같아 꾹 참고 기다리기로 했습니다. 당연하겠지만, 앞 사람들이 중간에 지쳐서 나가지 않는다면 앞 사람들이 모두 들어가야 여러분들이 들어갈 기회가 생기겠죠?

![](https://contents.codetree.ai/problems/517/images/introductions-616e6fd8-5617-4636-9570-f593e2406000.svg)

이런식으로 줄을 설 때, 먼저 줄을 선 사람이 먼저 식당에 입장할 수 있다는 것은 길게 설명하지 않아도 모두가 알 것입니다.

우리는 이런 구조를 선입선출 구조 (FIFO; First In First Out) 라고 부르는데, 이번에 배울 큐 라는 자료구조는 이 선입선출 구조를 따르고 있는 구조입니다.

queue는 크게 5가지 함수 사용이 가능합니다.

1. `push(x)`

x를 queue의 맨 뒤에 추가합니다.

![](https://contents.codetree.ai/problems/517/images/introductions-26f7a7fc-d416-4163-8fcd-251c103e1487.png)

![](https://contents.codetree.ai/problems/517/images/introductions-08c1cdad-ba7f-4527-aea9-840d2310ee4e.png)

![](https://contents.codetree.ai/problems/517/images/introductions-38025938-01ba-4f95-a154-ba3a49edee3e.png)

2. `size()`

queue 안에 들어있는 데이터의 개수를 반환합니다.

![](https://contents.codetree.ai/problems/517/images/introductions-1e739b37-e6ac-4018-afc2-2de4feddadba.png)

![](https://contents.codetree.ai/problems/517/images/introductions-e12c723b-c572-43be-9fc5-5291a85d2711.png)

3. `empty()`

queue 안에 남아있는 데이터가 없다면 true, 있다면 false를 반환합니다.

![](https://contents.codetree.ai/problems/517/images/introductions-5bbcbaa0-496b-4737-aaf6-e220686f9f83.png)

![](https://contents.codetree.ai/problems/517/images/introductions-421249cf-7d19-4a32-8d4a-25393faa0671.png)

4. `front()`

queue의 맨 앞에 있는 숫자 값을 반환합니다. 단, queue에서 해당 데이터를 제거하지는 않습니다.

![](https://contents.codetree.ai/problems/517/images/introductions-0fd7151a-c3f0-4455-a5f2-da7edff0a425.png)

![](https://contents.codetree.ai/problems/517/images/introductions-f3e89f20-52da-4694-af4b-c7cb3f884e94.png)

5. `pop()`

queue의 맨 앞에 있는 숫자 값을 반환합니다. 단, 동시에 queue에서 해당 데이터를 제거합니다.

![](https://contents.codetree.ai/problems/517/images/introductions-7406e681-71ed-4265-a972-0bad9b262ade.png)

![](https://contents.codetree.ai/problems/517/images/introductions-0d5f6440-f8e8-482f-a955-b342e3750645.png)

![](https://contents.codetree.ai/problems/517/images/introductions-e39d8865-feb5-44ec-ad0a-4abb62204be6.png)

여러 연산이 순서대로 실행되었을 때의 모습은 다음과 같습니다.

비록 데이터의 삽입과 삭제가 동일한 장소에서 수행되지는 않지만, 다른 값들의 이동이 필요하지 않기 때문에 여전히 삭제와 삽입의 시간복잡도는 $O(1)$ 으로 동일합니다.
