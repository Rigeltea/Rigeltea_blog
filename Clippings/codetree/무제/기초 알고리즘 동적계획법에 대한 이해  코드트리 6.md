## 이상한 파도반

Medium

10XP

평균 2분

59% 정답률

총 제출 2,809회

아래 코드는 파도반 수열을 바텀업 방식을 통해 구하는 코드입니다.

파도반 수열이란 다음을 만족하는 수열입니다.

```
점화식   - P(N) = P(N-2) + P(N-3)    (N > 3)
초기 조건 - P(1) = 1, P(2) = 1, P(3) = 1
```

빈 칸에 알맞은 코드를 넣어주세요.

```jsx
function solution(n)
    dp = [0, 0, 0, ...]
    dp[1] = 1
    dp[2] = 1
       (1)

    for i = 4 ... i <= n
        dp[i] = (2) + dp[i - 2]
  
    return (3)
```
