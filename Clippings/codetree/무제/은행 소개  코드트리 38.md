개선된 Union-Find(경로압축을 적용한 경우)를 사용하여 다음과 같은 연산을 진행하였습니다.

```js
function init(size)
  set uf = [0] with size
  for i = 1 ... size
    uf[i] = i
  return uf

function find(x)
  if uf[x] == x
    return x
  return uf[x] = find(uf[x])
  
function union(x, y)
  set X = find(x), Y = find(y)
  uf[X] = Y

uf = init(5)
union(1, 2)
union(2, 4)
union(3, 4)
union(5, 1)

find(2)
find(4)
```

모든 연산을 수행했을 때, $uf$ 의 상태는 어떻게 표현될까요?

이 콘텐츠가 도움이 되었나요?
