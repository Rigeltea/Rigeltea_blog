Lesson 4. Bitmask DP

기본 문제에서는 단계별 학습을 위해 각 문제가 하나의 기본개념과 짝을 이룹니다. 연습 문제와 테스트 문제에서는 쉽게 복습할 수 있도록 모든 개념이 함께 제공됩니다.

## 0, 1 상태와 DP

다음 문제는 어떻게 해결해볼 수 있을까요?

```
2 × 30 크기의 사각형을 1 × 2, 2 × 1 크기의 사각형들로 채우는 
방법의 수를 구하는 프로그램을 작성해보세요. 
단 가짓수가 많아질 수 있기에 해당 수를 10,007로 나눈 나머지를 구해야합니다.

예로 2 x 2일 때는 다음과 같이 2가지 방법이 가능합니다.
```

![](https://contents.codetree.ai/problems/2493/images/introductions-41ff5870-000e-4221-b62d-979b84809ef1.png)

규칙을 찾아서 점화식을 세워서 풀 수도 있지만, 수학적인 규칙 없이 이를 정직한 DP로 풀어볼 수 있습니다.

왼쪽부터 순서대로 블럭을 채워나간다고 했을 때 i번째 열까지는 이미 다 채워져 있다고 생각해봅시다. 이제 i + 1번째 행을 채우기 위해서는 **바로 직전 행인 i 번째 행에 채워진 블럭의 모양** 이 중요합니다. 그 이유는 i번째 행을 채우기 위해 1x2 크기의 블럭을 사용했다면 이는 i + 1번째 행까지 채워지게 되어 영향을 끼치게 되기 때문입니다.

![](https://contents.codetree.ai/problems/2493/images/introductions-36fa7b90-128a-4b7b-9943-cbac76b35752.png)

따라서 `dp[i][j1][j2] : i번째 열 직전까지는 전부 꽉 채웠고 i - 1번째 열에 놓은 블록 모양에 따라 i번째 열까지 튀어나온 모양이 1행, 2행 순서대로 j1, j2가 되는 서로 다른 가짓수 (단, j1, j2이 1이면 튀어나옴 / 0이면 튀어나오지 않음)` 라고 정의해볼 수 있습니다. 아래는 각각 dp\[3\]\[1\]\[0\], dp\[3\]\[0\]\[0\]에 해당하는 그림입니다.

![](https://contents.codetree.ai/problems/2493/images/introductions-6a13501a-b034-43cc-a653-efbbd5d86315.png)

이제 여기서 점화식을 세우기 보다는 **뿌려지는 형태의 동적계획법** 을 진행해보려고 합니다. 보통의 동적계획법 문제는 점화식을 세워 작은 문제에 해당하는 이전 값들이 채워져있다는 가정 하에서 현재 상태에 해당하는 최적의 값을 계산하는 식으로 진행됩니다. 이러한 방식은 `이미 완성된 값을 가져오는 형태의 동적계획법` 입니다. 하지만 상황에 따라 가져와야 할 부분을 직관적으로 떠올리거나 정리하는 것이 어려운 경우가 더러 있습니다. 지금 이 문제에서는 점화식을 세워 가져오는 방법으로 진행하기보다는, **이미 값이 구해져있다는 가정 하에서 이 상태가 영향을 미치는 그 다음 상태를 찾아 값을 갱신해주는 식인** 뿌려지는 형태의 동적계획법을 진행해보려고 합니다.

먼저 `dp[i][0][0]` 값이 이미 구해져있다고 가정해보겠습니다. 그렇다면 아래와 같은 상황이 됩니다.

![](https://contents.codetree.ai/problems/2493/images/introductions-93f3e703-94fc-4e55-8dbd-0371367a10c1.png)

이 상황에서 i번째 열을 꽉 채우기 위해서는 1) 2x1 블럭을 i번째 열에 사용하거나 2) 1x2 블럭을 2개 사용하는 경우밖에 없습니다. 채워진 이후의 각각의 상태는 `dp[i+1][0][0]`, `dp[i+1][1][1]` 이 됩니다.

![](https://contents.codetree.ai/problems/2493/images/introductions-db2eb852-a92c-4e2b-b9f3-f4ae1da2da1a.png)

마찬가지 방법으로 `dp[i][0][1]` 값이 이미 구해져 있었다면 i번째 열을 꽉 채우기 위해서는 1x2 블럭을 하나 사용하는 경우밖에 없습니다. 채워진 이후의 상태는 `dp[i+1][1][0]` 이 됩니다.

![](https://contents.codetree.ai/problems/2493/images/introductions-50cacddc-03c5-46cc-bac6-f1a3a28a3f66.png)

또, `dp[i][1][0]` 값이 이미 구해져 있었다면 i번째 열을 꽉 채우기 위해서는 1x2 블럭을 하나 사용하는 경우밖에 없습니다. 채워진 이후의 상태는 `dp[i+1][0][1]` 이 됩니다.

![](https://contents.codetree.ai/problems/2493/images/introductions-8697a075-2329-4ba9-8073-d3f88d254688.png)

끝으로 `dp[i][1][1]` 값이 이미 구해져 있었다면 i번째 열은 이미 꽉 채워져 있기 때문에 블럭을 추가로 사용할 수 없습니다. 따라서 이후의 상태는 `dp[i+1][0][0]` 이 됩니다.

![](https://contents.codetree.ai/problems/2493/images/introductions-c8fcbf40-e823-4aa3-822a-94609afede2c.png)

초기조건은 아직 아무것도 채우지 않은 상태인 1번째 열 직전까지는 전부 꽉 채웠고 1번째 열에는 튀어나온 모양이 없는, 즉 j1 j2 모두 0이 되는 가짓수가 1가지임을 의미하는 `dp[1][0][0] = 1` 이 됩니다. 이후 점화식에 따라 값을 채워주면 되기에 $O(N)$ 에 문제에서 원하는 답을 구할 수 있게 됩니다. 해당 코드는 아래와 같습니다.

```python
MOD = 10007

# 변수 선언 및 입력:
n = 30

# dp[i][j1][j2] :
#   i번째 열 직전까지는 전부 꽉 채웠고
#   i - 1번째 열에 놓은 블록 모양에 따라
#   i번째 열까지 튀어나온 모양이
#   1행, 2행 순서대로 j1, j2가 되는
#   서로 다른 가짓수
#   단, j1, j2가 1이면 튀어나옴 / 0이면 튀어나오지 않음
dp = [
    [
        [0, 0]
        for _ in range(2)
    ]
    for _ in range(n + 2)
]
   
# 초기조건은 아직 아무것도 채우지 않은 상태인
# 1번째 열 직전까지는 전부 꽉 채웠고
# 1번째 열에는 튀어나온 모양이 없는,
# 즉 j1 j2 모두 0이 되는 가짓수가
# 1가지임을 의미하는 dp[1][0][0] = 1이 됩니다.
dp[1][0][0] = 1

# 뿌려주는 dp를 진행합니다.
# dp[i][j1][j2]값이 이미 계산되어 있다는 가정하에
# 그 다음 상태를 계산합니다.
for i in range(1, n + 1):
    # dp[i][0][0]에서 나올 수 있는 모양을 전부 갱신합니다.
    dp[i + 1][0][0] = (dp[i + 1][0][0] + dp[i][0][0]) % MOD
    dp[i + 1][1][1] = (dp[i + 1][1][1] + dp[i][0][0]) % MOD

    # dp[i][0][1]에서 나올 수 있는 모양을 전부 갱신합니다.
    dp[i + 1][1][0] = (dp[i + 1][1][0] + dp[i][0][1]) % MOD

    # dp[i][1][0]에서 나올 수 있는 모양을 전부 갱신합니다.
    dp[i + 1][0][1] = (dp[i + 1][0][1] + dp[i][1][0]) % MOD

    # dp[i][1][1]에서 나올 수 있는 모양을 전부 갱신합니다.
    dp[i + 1][0][0] = (dp[i + 1][0][0] + dp[i][1][1]) % MOD

# n번째 열까지 전부 꽉 채웠고
# n + 1번째 열에는 튀어나온 모양이 없는 경우가 (=j값이 전부 0, 0)
# 문제에서 원하는 완벽하게 채운 상태가 됩니다.
print(dp[n + 1][0][0])
```

따라서 0, 1을 문제 특성에 따라 dp의 상태로 나타내면 수학적 규칙 없이도 다양한 문제들을 해결할 수 있게 됩니다.
