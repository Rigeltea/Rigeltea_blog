Lesson 4. Bitmask DP

## 사각형 채우기 5

Easy

30XP

평균 36분

78% 정답률

총 제출 46회

$4 \times n$ 크기의 사각형을 1 × 2, 2 × 1 크기의 사각형들로 채우는 방법의 수를 구하는 프로그램을 작성해보세요

예로 $n = 2$ 일 때는 다음과 같이 5가지 방법이 가능합니다.

![](https://contents.codetree.ai/problems/3466/images/problems-6d326a14-689d-438e-9e43-1d6ecef61951.png)

### 입력

첫 번째 줄에 $n$ 이 주어집니다.

### 제한 조건

- $2 \leq n \leq 1,000$

### 출력

$4 \times n$ 크기의 사각형을 채우는 방법의 수를 10,007로 나눈 나머지를 출력합니다.

### 입력 예제

### 예제 1

입력

```
2
```

출력

```
5
```

### 예제 2

입력

```
3
```

출력

```
11
```
