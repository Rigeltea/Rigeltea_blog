Lesson 1. HashMap

## 원소의 합이 0

Hard

90XP

평균 73분

63% 정답률

총 제출 1,249회

네 개의 수열 $A$, $B$, $C$, $D$ 에서 각각 원소를 하나씩 골라 더하였을 때 합이 $0$ 이되는 경우의 수를 구하는 프로그램을 작성해보세요.

### 입력

첫 번째 줄에 수열의 크기 $N$ 이 주어집니다.

두 번째 줄 부터 $4$ 개의 줄에 거쳐 네 개의 수열 $A$, $B$, $C$, $D$ 이 한 줄씩 차례대로 각각의 원소가 공백을 두고 출력됩니다.

### 제한 조건

- $1 \leq N \leq 5\,000$
- $-1\,000\,000\,000 \leq \texttt{원소의 크기} \leq  1\,000\,000\,000$

### 출력

합이 $0$ 이 되는 경우의 수를 출력합니다.

### 입력 예제

### 예제 1

입력

```
6
-45 -41 -36 -36 26 -32
22 -27 53 30 -38 -54
42 56 -37 -75 -10 -6
-16 30 77 -46 62 45
```

출력

```
5
```

예제 설명

접기

다음과 같이 5가지의 경우가 가능합니다.

```
A   B   C   D

-45 -27  42  30
 26  30 -10 -46
-32  22  56 -46
-32  30 -75  77
-32 -54  56  30
```

### 제한

• Time Limit: 1000 ms

• Memory Limit: 120 MiB
