## 문자열을 마치 Array의 Index 처럼 사용하기

다음 문제를 생각해봅시다.

```
서로 다른 6개의 문자열이 주어진 뒤 끝에 문자열 K가 주어졌을 때, 
문자열 K가 몇 번째로 주어졌는지를 판단하는 프로그램을 작성해보세요.

예를 들어 ["aba", "banana", "apple", "code", "tree", "foo"] 에서
K가 "banana"라면, 2번째로 주어진 문자열이므로 답은 2가 됩니다.
```

for loop을 돌려 직접 문자열 K가 어디에 들어있는지를 탐색한다면, 시간복잡도는 $O(N)$ 이 될 것입니다.

하지만 이 경우에는 각 문자열이 마치 배열의 index처럼 쓰이듯이 dict를 이용하여 (key, value) 형태로 각 문자열이 몇 번째 index에 있었는지를 저장해주면, 문자열 K가 주어졌을 때 $O(1)$ 만에 K가 몇 번째로 주어졌는지를 판단할 수 있습니다.

```python
n = int(input())
words = list(input().split())
k = input()

string_to_index = {}

for i, elem in enumerate(words):
    string_to_index[elem] = i + 1

print(string_to_index[k])

>>
입력
6
aba banana apple code tree foo
banana

출력
2
```
