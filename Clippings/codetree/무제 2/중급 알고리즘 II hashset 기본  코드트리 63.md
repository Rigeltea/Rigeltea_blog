Lesson 1. Greedy Algorithm

기본 문제에서는 단계별 학습을 위해 각 문제가 하나의 기본개념과 짝을 이룹니다. 연습 문제와 테스트 문제에서는 쉽게 복습할 수 있도록 모든 개념이 함께 제공됩니다.

## 최대 숫자 만들기

다음 문제를 살펴봅시다.

```
[43, 39, 444]

이렇게 3개의 숫자가 주어졌을 때, 
적당한 순서에 맞춰 나열하여 각 숫자들을 붙여 만들 수 있는 숫자 중 
가능한 최댓값을 구하는 프로그램을 작성해보세요.
```

이 문제도 그리디로 풀어볼 수 있지 않을까요?

> 가장 먼저 떠오르는 생각은.  
> 가장 큰 자리부터 봤을 때 더 큰 숫자가 먼저 나오는 숫자를 선택할수록 답이 더 커지게 되지 않을까요?

위에 예시에서는 우선 4로 시작하는 숫자들이 먼저 나와야 하고,  
4로 시작하는 숫자 43, 444 중 2번째 자리 숫자가 더 큰 444가 더 먼저 나오면 좋을 것이기에  
444, 43, 39 순으로 나열하여 `4444339` 를 만드는 것이 가장 좋아보입니다.

맞습니다. 하지만 이 문제의 어려움은 바로 `4` 와 `43` 과 같이  
**한 숫자가 다른 숫자의 접두사가 되는 경우입니다.**

474, 4 이렇게 2개의 숫자가 주어진 경우라면 다음과 같이 숫자 474가 더 앞에 오는 것이 좋습니다 `"474"4" > "4"474"`  
하지만 43, 4 이렇게 2개의 숫자가 주어진 경우라면 다음과 같이 숫자 4가 더 앞에 오는 것이 좋습니다. `"4"43" > "43"4"`  
따라서 서로 포함관계에 있는 경우라면 포함되는 숫자 / 포함하는 숫자 중 어떤 숫자가 더 앞에 올 수 있을지에 대한 순서를 정하기가 애매합니다.

이런 경우에는 기준을 **직접 두 숫자 a, b를 ab, ba 형태로 붙여봤을 때 값이 더 큰 경우에 해당하는 숫자가** 앞으로 오도록 정렬 기준을 설정하면 됩니다.  
474, 4의 경우에는 두 숫자를 서로 붙여봤을 때 `"474"4" > "4"474"` 를 만족하므로 474를 더 앞으로 보내주고,  
43, 4의 경우에는 두 숫자를 서로 붙여봤을 때 `"4"43" > "43"4"` 를 만족하므로 4를 더 앞으로 보내주면 됩니다.

이렇게 선택된 2개의 값을 모두 고려하여 정렬 기준을 새롭게 설정하는 경우에는 python에서 lambda 함수만으로는 해결이 어렵기 때문에 꼭 custom comparator를 정의하여 해결해야 합니다. python3에서는 custom comparator를 만들고 sort함수의 key 인자로 넘길때 꼭, **functools내 cmp\_to\_key** 함수를 import하여 `cmp_to_key(compare)` 식으로 감싸줘야 합니다.

또, 정렬의 기준을 나타내는 함수인 `compare` 함수에는 인자를 2개 설정해줘야 합니다. 이를 x, y라 한다면 x가 앞에 있는 원소, y가 뒤에 있는 원소라 가정했을 때 이 순서가 우리가 원하는 순서라면 0보다 작은 값을, 반대라면 0보다 큰 값을, 둘의 우선순위가 동일하다면 0을 반환하는 함수를 작성해줘야 합니다. 이때 보통 반환값에 1, -1, 0을 사용합니다.

다음은 custom comparator를 이용해 숫자들을 내림차순 정렬하는 예시입니다.

```python
from functools import cmp_to_key

# custom comparator를 직접 정의
# x가 앞에 있는 숫자, y가 뒤에 있는 숫자 가정했을 때
# 이 순서가 우리가 원하는 순서라면 0보다 작은 값을, 
# 반대라면 0보다 큰 값을
# 둘의 우선순위가 동일하다면 0을 반환하면 됩니다.
# 보통 반환값에 1, -1, 0을 사용합니다.
def compare(x, y):
    # x가 y보다 크다면
    # 우리가 원하는 방향입니다.
    if x > y:
        return -1
    # y가 x보다 크다면
    # 우리가 원하지 않는 방향입니다.
    if y > x:
        return 1
    # 우선 순위가 동일한 경우입니다.
    return 0

arr = [4, 2, 8, 5, 9]

# 내림차순 정렬
arr.sort(key=cmp_to_key(compare))

for elem in arr: # 정렬 이후의 결과 출력
    print(elem, end=" ")

>> 9 8 5 4 2
```
