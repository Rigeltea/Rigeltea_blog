Lesson 2. Parametric Search

## 삼 오 무

Easy

40XP

평균 38분

39% 정답률

총 제출 1,328회

$1$ 부터 차례대로 숫자를 적는데, $3$ 이나 $5$ 의 배수는 숫자 대신 "Moo"라고 적습니다. 예를 들어 $1$ 부터 $16$ 까지의 숫자를 적는다면 아래와 같습니다.

$1$, $2$, Moo, $4$, Moo, Moo, $7$, $8$, Moo, Moo, $11$, Moo, $13$, $14$, Moo, $16$

이 때, $N$ 번째로 적히는 숫자는 무엇인지 구하는 프로그램을 작성해보세요.

### 입력

첫 번째 줄에 $N$ 이 주어집니다.

### 제한 조건

- $1\le N\le10^9$

### 출력

첫 번째 줄에 $N$ 번째로 적히는 숫자를 출력합니다.

### 입력 예제

### 예제 1

입력

```
4
```

출력

```
7
```

예제 설명

접기

적히는 숫자들은 $1$, $2$, $4$, $7$, $\dots$ 이므로 $4$ 번째 적히는 숫자는 $7$ 입니다.

### 제한

• Time Limit: 1000 ms

• Memory Limit: 80 MiB
