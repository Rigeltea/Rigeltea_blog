Lesson 2. 상태 반전이 가능한 문제

## 상하좌우 반전시키기

Hard

90XP

평균 103분

71% 정답률

총 제출 167회

숫자 0과 1로만 이루어진 $n \times n$ 크기의 격자 상태가 주어집니다. 첫 번째 행을 제외한 위치에 있는 칸을 누르는 것이 가능하고, 특정 칸을 누르게 되면 해당 칸에 있는 숫자 뿐 아니라 바로 상하좌우 인접한 칸에 있는 숫자 까지도 전부 반전시키게 됩니다. 여기서 반전이란 숫자 0이 1이 되고, 숫자 1이 0이 되는 것을 의미합니다. 적절하게 칸을 눌러 최종적으로 $n \times n$ 크기의 격자에 적혀있는 숫자가 전부 1이 되도록 하는 최소 클릭 횟수를 출력하는 프로그램을 작성해보세요. 단, 상하좌우 인접한 칸 중 격자를 벗어나는 칸에 대해서는 반전이 일어나지 않으며, 누른 칸을 또 누르는 것 역시 가능함에 유의합니다.

예를 들어, $n$ 이 3이고 입력으로 주어진 격자 상태가 다음과 같은 경우를 생각해봅시다.

```
0 1 0
0 1 0
0 1 0
```

이때 처음 2행 1열 칸을 선택하면 다음과 같이 상태가 바뀌게 됩니다.

```
0 1 0         1 1 0
0 1 0   ->    1 0 0
0 1 0         1 1 0
```

그 다음 2행 3열 칸을 선택하면 다음과 같이 숫자를 전부 1로 만들 수 있게 됩니다.

```
1 1 0         1 1 1
1 0 0   ->    1 1 1
1 1 0         1 1 1
```

### 입력

첫 번째 줄에 $n$ 이 주어집니다.

두 번째 줄부터는 $n$ 개의 줄에 걸쳐 각 줄마다 각각의 행에 해당하는 $n$ 개의 숫자가 공백을 사이에 두고 주어집니다. 전부 0과 1로 이루어져 있다고 가정해도 좋습니다.

### 제한 조건

- $1 \le n \le 100$

### 출력

숫자를 전부 1로 만들기 위해 눌러야 할 최소 횟수를 출력합니다. 만약 전부 1로 만드는 것이 불가능하다면 -1을 출력하세요.

### 입력 예제

### 예제 1

입력

```
3
0 1 0
0 1 0
0 1 0
```

출력

```
2
```

• Time Limit: 1000 ms

• Memory Limit: 80 MiB
