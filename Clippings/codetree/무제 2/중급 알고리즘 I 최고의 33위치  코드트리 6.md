Lesson 2. TreeMap

기본 문제에서는 단계별 학습을 위해 각 문제가 하나의 기본개념과 짝을 이룹니다. 연습 문제와 테스트 문제에서는 쉽게 복습할 수 있도록 모든 개념이 함께 제공됩니다.

## 사전순으로 빈도수와 함께 나열하기

여러 단어들이 주어졌을 때, 각 단어가 몇 번씩 주어졌는지를 **사전순으로** 앞선 단어가 먼저 나오도록 하여 출력하는 코드는 어떻게 작성해볼 수 있을까요?

이 경우 역시 SortedDict를 활용하면 됩니다. treemap은 key를 기준으로 사전순 정렬을 해주며, key가 문자열인 경우에도 동일하게 적용됩니다.

```python
from sortedcontainers import SortedDict

sd = SortedDict()      # treemap
sd["banana"] = 6
sd["apple"] = 2
sd["cat"] = 1

for key, value in sd.items():
    print(key, value)

>> 결과
apple 2
banana 6
cat 1
```
