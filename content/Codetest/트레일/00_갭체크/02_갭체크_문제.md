## 0. 미해결(정답도 못구함)
- 현시점 BFS를 진행헀지만 밑에 있는 문제는 정답을 구해도 정답을 찾아서 돌려보지 못하기 때문에 서로 

- n, k =  3, 3 일때 답이 6인지 3인지 에 따라서
- 바라보는 방향이 달라서 dp공부로 해야 풀 수 있을거 같음..
-  dp를 배우고 테스트에서 이 문제가 나오면 다 넣어 보면 될듯함

```python
n, k = map(int, input().split())
arr = [list(map(int, input().split())) for _ in range(n)]

# d=0: 아래,  d=1: 오른쪽
dxs = [1, 0]
dys = [0, 1]

count = 0

def in_range(x, y):
    return 0 <= x < n and 0 <= y < n

def dfs(x, y, d, curk):
    global count
    if curk > k:           # 전환 한도 초과 → 가지치기
        return
    if x == n - 1 and y == n - 1:   # 목적지 도착
        count += 1
        return

    # 1) 직진 (방향 유지, curk 그대로)
    nx, ny = x + dxs[d], y + dys[d]
    if in_range(nx, ny) and arr[nx][ny] == 0:
        dfs(nx, ny, d, curk)

    # 2) 방향 전환 (d 뒤집고 curk+1)
    nd = 1 - d
    nx, ny = x + dxs[nd], y + dys[nd]
    if in_range(nx, ny) and arr[nx][ny] == 0:
        dfs(nx, ny, nd, curk + 1)

# 시작: 첫 방향 선택은 전환이 아니므로 첫 이동을 직접 시드
if in_range(1, 0) and arr[1][0] == 0:   # 아래로 출발
    dfs(1, 0, 0, 0)
if in_range(0, 1) and arr[0][1] == 0:   # 오른쪽으로 출발
    dfs(0, 1, 1, 0)

print(count)
```
