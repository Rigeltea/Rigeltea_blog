## 0. 미해결

### 1. backtracking 관련 함수를 제작하는데 있어서 이해 못함
- if 문 순서를 잘못 적음 
  (idx == 7를 먼저 적음 따라서 내가 생각한 형태가 안나와서 타임 지나감 )
```python
def choose(idx, selected):     
    
    
    if len(selected) == 3:  
        return  
    
    # 나중에 적어야 함
    # len(selected) 보다 먼저 적으면 6 들오면 
    # 다른 if 문 돌아보지 못하고 바로 리턴함
    if idx == 7:  
        return      



    selected.append(idx)  
    choose(idx+1, selected)  
    selected.pop()  
  
    choose(idx+1, selected)  
  
    return


```

### 2. in 형태를 까먹음 & 방법론 적용
- 나는 뽑을 숫자를 바탕으로 (a,b,c) => (a,a) (a,b) ~~ (c,c) 형태로 만들고 lst안에 있나 확인하려고 했다. 
- ```if a in lst and b in lst``` 를 사용했다면 더욱 간단히 접근이 가능했다.

```python
lst = [(1,1),(1,2),(2,3),(4,5),(2,4),(5,6)]

if len(selected) == 3:  
  
    cnt = 0  
    for a, b in lst:  
        if a in selected and b in selected:  
            cnt += 1  
    print(selected, cnt)  
    answer = max(answer, cnt)  
    return
```

### 최종 코드
```python
lst = [(1,1),(1,2),(2,3),(4,5),(2,4),(5,6)]  
  
answer = 0  
def choose(idx, selected):  
    global answer  
    if len(selected) == 3:  
  
        cnt = 0  
        for a, b in lst:  
            if a in selected and b in selected:  
                cnt += 1  
        print(selected, cnt)  
        answer = max(answer, cnt)  
        return  
  
    if idx == 7:  
        return  
  
  
  
    selected.append(idx)  
    choose(idx+1, selected)  
    selected.pop()  
  
    choose(idx+1, selected)  
  
    return  
  
choose(1,[])  
print(answer)
```
