### 1. 조건문 차이
나는 range 안에서 조건문을 만드는것을 생각하지못하고 
바로 함수를 만들었다.

특히 여기서 많이 놀랐다. 
```range(i-k, i+1,+1)``` 에서 놀랐다.
나는 항상 1 ~10 범위 일 때 range(10)으로 들어가야 생각했다.
하지만 범위는 넣은 다음에 필터링 할 수 있다는 부분에서 많은 생각을 가지게 되었다.

## 3. 접근 방법

### 1. 슈도 코드
```
# n, k 입력 받는다.
# range(n)
# candy
# location

# 범위를 2n+1로 리스트 범위를 만드느게 좋겠다.
# range(n)

# 바구니 갯수는 n
# 바구니 위치는 0 < 100 까지
# 하지만 k 구간은 200까지
# c =0 이라고 과정하면
# - 200 부터 200까지를 봐야하는 상황이 생김

```


```python

n, k = map(int, input().split())
lst = [0]*101
for i in range(n):
    candy, location = map(int,input().split())
    lst[location] += candy


def se(c, k):
    if c-k>=0:
        s = c-k
    else:
        s = 0

    if c+k <= 100:
        e = c+k+1 # lst[:] 형태로 만들 예정
    else:
        e = 101
    return s,e

answer = 0
for c in range(100):
    s,e = se(c,k)

    answer = max(answer, sum(lst[s:e]))

print(answer)

```
