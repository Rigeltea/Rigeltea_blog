```python
		cnt += 1

print(cnt)
```

### 1. 슈도 코드
```
# n,m 입력 받는다.
#range(n-m+1):
# a[i:i+m] 일때
# 거기 안에 b가 다 있으면 아름다운 수열이라고 생각하면 될거 같다.
```

하지만 계속 실패가 나왔다.

b에 list를 넣으면
list 에 b를 넣으면

list안에 b 넣고 b에 list 있는거 까지 다 했는데
다 예외 경우가 있었다.
그래서
현타가 와서 마지막으로 카운팅을 때려 봐렸다....

슈도 코드 작성시 예외 처리를 제대로 하지 않았다.
너무 쉬워 빨리 풀고 넘어가려고 해서 이런 사단이 난거 같다.

```python
n,m = map(int, input().split())
a = list(map(int, input().split()))
b = list(map(int,input().split()))

answer = 0
for i in range(n-m+1):
    cnt = 0
    for j in range(m):
        if b[j] in a[i:i+m]:
            cnt += 1
        else:
            break
    
    if cnt == m:
        answer += 1

print(answer)

# 2번쨰
for i in range(n-m+1):
    arr = a[i:i+m]
    cnt = 0
    for j in arr:
        if j in b:
            cnt += 1

    if cnt == m:
        answer += 1
        
# 3번재
for i in range(n-m+1):
    lst = a[i:i+m]

    cnt = 0
    for j in range(m):
        if lst[j] in b and b[j] in lst:
            cnt += 1

    if cnt == m:
        answer +=1



# 정답

value_b = [0]*101

for i in b:

    value_b[i] += 1

  
  

answer = 0

for i in range(n-m+1):
    value_lst = [0]*101
    
    for j in  a[i:i+m]:
        value_lst[j]+= 1

    if value_b == value_lst:
        answer+= 1

  

print(answer)
```
