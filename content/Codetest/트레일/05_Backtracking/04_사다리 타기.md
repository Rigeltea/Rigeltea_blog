## 1. 문제

사다리 타기 게임은 사람 수 N 만큼 세로줄을 긋고 위쪽 편에는 1부터 N까지의 숫자를 순서대로 적은 다음, 몇몇 인접한 세로줄 사이에 가로줄 M개를 서로 겹치지 않게 긋습니다.

이후 위쪽에 있는 각 숫자에서 부터 시작하여 내려가다가 교점을 만날 때마다 90도로 방향을 꺾다 끝에 도착하게 되면 해당 숫자를 적는 게임입니다.

이 게임에서는 가로줄끼리 서로 맞닿아 있는 경우가 없다고 가정해도 좋습니다.

예를 들어 N이 4, M이 6이고 다음과 같이 가로줄이 주어졌을 때의 결과는 3, 4, 1, 2가 됩니다.

## 4. 주의할 점

먼저 나는 1번 내려가고 2번 내려가고
이와 같이 하나씩 진행하는 방법으로 진행했다.

그런데 여기서는 가로줄 1~6 으로
전체적으로 변화를 주었다.

이부분에서 나는 새로운 것을 알게 되었다.

굳이 사다리 같은 문제에서는 전체를 비교하면서 내려가는게 좋다는 사실을 알았다.
스왑 하는 방식을 알게 된거 같다.


또한 접근 법이다.
우리는 루프를 만드는 것도 좋은데

루프의 조건을 넣는것도 중요하다

그래서 조건에 먼저 만들고
루프를 Choose를 만든게 좋다는 사실을 다시한번 알게 되었다.


솔직히 슈도 코드 작성이 어려울거 같다.

솔직히 아직 작성할때
answer을 list를 넣어야 하나
m으로 넣어야 하나 헷갈림.

-> 이거는 많이 풀어봐야 알거 같다.


#### GPT

##### 1단계: 원래 결과 구하기

```text
가로줄 정보를 입력받는다

b가 높이이므로 b 기준으로 정렬한다

simulate(사용할 가로줄 목록):
    arr = [1, 2, 3, ..., n]

    사용할 가로줄을 하나씩 본다
        해당 가로줄의 a를 확인한다
        arr[a-1]과 arr[a]를 바꾼다

    arr를 반환한다

target = 모든 가로줄을 사용했을 때 simulate 결과
```

여기서 `target`은 **원래 사다리 결과**야.

---

##### 2단계: 가로줄을 고르는 재귀 만들기

```text
selected = []
answer = 매우 큰 값

choose(idx):
    만약 idx == m 이라면:
        selected로 simulate를 돌린다

        결과가 target과 같다면:
            answer = min(answer, selected 개수)

        return

    idx번째 가로줄을 사용하지 않는다
        choose(idx + 1)

    idx번째 가로줄을 사용한다
        selected에 idx 추가
        choose(idx + 1)
        selected에서 idx 제거
```

최소 개수를 찾으니까 **안 고르는 경우를 먼저** 보는 게 좋아.

---

##### 3단계: 가지치기 추가하기

```text
choose(idx):
    만약 selected 개수가 이미 answer 이상이라면:
        더 볼 필요 없으므로 return

    만약 idx == m 이라면:
        simulate(selected)가 target과 같은지 확인
        같으면 answer 갱신
        return

    사용 안 함
    사용함
```

---

전체 흐름은 이렇게 보면 돼.

```text
입력
↓
가로줄을 높이 기준으로 정렬
↓
모든 가로줄을 사용한 결과 target 구하기
↓
selected = []로 시작
↓
각 가로줄을 사용할지 말지 재귀로 전부 선택
↓
선택된 가로줄만으로 simulate
↓
target과 같으면 최소 개수 갱신
↓
answer 출력
```

핵심 문장으로 외우면:

> **simulate는 결과를 만드는 함수, choose는 사용할 가로줄 조합을 만드는 함수**

이렇게야.
