## 3. 접근 방법

### 1.  n을 입력받는다. n*n 격자에 들어간 값을 받는다.
	-> 2차배열은  = 형태로 복사가 안된기 떄문에 값을 추출하기로 결정함

### 2.  폭탄 위치를 추출
```
-> for i in range / for j in range => grid['i']['j'] == 1 일떄 기준
```

### 3. 모든 곳을 둘러봐야 하기 때문에  대표적인 재귀함수를 사용해서 어떻게 사용할지 고민함
```python
# backtracking 대표적인 재귀 구현

n = 3
answer = []

def choose(curr_num):
	if curr_num == n:
	  print(answer)
	  return
	
	for select in range(2):
	  answer.append(select)
	  choose(curr_num +1)
	  answer.pop()
	
	
	return

```


### 4. 조건 추가 하기
	1. 조건을 보면 폭탄의 모양이 3개 였기 떄문에  ```for select in range(3) ``` 을 사용하면 되겠구나 라고 생각을 했습니다.

	2. 폭탄 지역마다 1~ 3개를 중 하나를 선택하기로 결정했기 떄문에 n은 폭탄 위치를 출력한 갯수 만큼 넣기로 생각했습니다.
		-> 폭탄이 2개라고 가정 하면 (0,0), (0,1), (0,2) ~~~ (2,1), (2,2) 
		-> 각 자리별 3*3 9가지 경우가 나오기 때문입니다.
		-> 따라서 n은 폭탄 갯수를 넣어주는 방식으로 진행하자 라는 생각을  했습니다.


### 5. 폭탄이 초토화 시킨 범위 확인하기

1. 앞서 말했든 2차원 배열은  equl 형태로 복사가 불가능합니다. 따라서 우리는 Boom 이라는 n*n 격자를 만들어 줍니다.

2. 저는 폭탄의 터지는 범위는 dx, dy technique를 이용했습니다. (주의 할점은 자신의 위치도 1를 추가해야 한다는 사실입니다.)

3. 격자 이기 떄문에 ```in_range(x,y)```를 만들어줬습니다 / 그리고 ```boom[ㅑ][ㅓ] == 1``` 일때 cnt +=1 주는 방식으로 범위를 체크했습니다. 



### 6. Code

```python
	
	n = int(input())
	grid = [list(map(int, input().split())) for _ in range(n)]
	
	
	lst = []
	for i in range(n):
	    for j in range(n):
	        if grid[i][j] == 1:
	            lst.append((i,j))
	
	num = len(lst)
	
	answer = []
	max_cnt= 0
	boom = [[0] * n for _ in range(n)]
	
	def choose(curr_num):
	    global max_cnt, boom
	
	    if curr_num == num:
	        boom = [[0] * n for _ in range(n)]
	
	        for i, j in zip(answer, lst):
	            max_cnt=max(max_cnt,boom_cnt(i, j))
	
	        # for row in boom:
	        #     print(*row)
	        # print("_"*10)
	        return
	
	    for select in range(3):
	        answer.append(select)
	        choose(curr_num +1)
	        answer.pop()
	    return
	
	
	def boom_cnt(i,j):
	    global boom
	    
	    if i == 0:
	        dx, dy = [1,2,-1,-2,0], [0,0,0,0,0]
	    elif i == 1:
	        dx, dy = [1,0,-1,0,0], [0,1,0,-1,0]
	    else: # i == 2:
	        dx, dy = [1,1,-1,-1,0],[1,-1,1,-1,0]
	
	    x, y = j
	    for k in range(5):
	        nx, ny = x+dx[k], y+dy[k]
	
	        if 0<=nx<n and 0<=ny<n:
	            boom[nx][ny] = 1
	
	    cnt = 0
	    for i in range(n):
	        for j in range(n):
	            if boom[i][j] == 1:
	                cnt+=1
	
	
	    return cnt
	
	
	choose(0)
	print(max_cnt)
	
```



## 4. 주의 할점
1. gobal boom, max_cnt를 사용하는데 많은 어려움이 있었음
	-> 개인적인 팀은 그냥 함수 여러곳에 쓰일거 같으면 그냥 글로벌을 해주는 방식이 가장 간단한거 같다.
	-> 그게 아니면 계속 에러가 나온다.
