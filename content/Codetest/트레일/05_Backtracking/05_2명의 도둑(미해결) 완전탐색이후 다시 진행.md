## 미해결
-> 문제를 해결하기 위해서는
-> 완전 탐색 알고리즘에 관련해서 제대로 이해를 해야한다.
-> 이해를 하지 못하면 접근하기 힘들다.


```
segments = []

모든 행 r에 대해:
    모든 시작 열 c에 대해:
        c부터 c+M-1까지가 한 도둑의 선택 구간

        이 구간 안에서
        무게 합이 C 이하가 되도록 물건을 골라
        얻을 수 있는 최대 가치 계산

        segments에 (행, 시작열, 끝열, 최대가치) 저장


answer = 0

segments에서 구간 2개를 고른다:
    첫 번째 구간 a
    두 번째 구간 b

    만약 같은 행이면:
        두 구간이 겹치면 안 됨

    겹치지 않는다면:
        answer = max(answer, a가치 + b가치)

출력 answer
```

```PYTHON
n, m, c = map(int, input().split())
grid = [list(map(int, input().split())) for _ in range(n)]


def get_best_value(items):
    best = 0

    def choose(idx, weight_sum, value_sum):
        nonlocal best

        if weight_sum > c:
            return

        if idx == m:
            best = max(best, value_sum)
            return

        # idx번째 물건을 고르는 경우
        choose(
            idx + 1,
            weight_sum + items[idx],
            value_sum + items[idx] ** 2
        )

        # idx번째 물건을 고르지 않는 경우
        choose(idx + 1, weight_sum, value_sum)

    choose(0, 0, 0)
    return best


segments = []

for row in range(n):
    for col in range(n - m + 1):
        items = grid[row][col:col + m]
        value = get_best_value(items)

        segments.append((row, col, col + m - 1, value))


answer = 0

for i in range(len(segments)):
    r1, s1, e1, v1 = segments[i]

    for j in range(i + 1, len(segments)):
        r2, s2, e2, v2 = segments[j]

        # 같은 행인데 겹치면 불가능
        if r1 == r2:
            if not (e1 < s2 or e2 < s1):
                continue

        answer = max(answer, v1 + v2)

print(answer)
```
