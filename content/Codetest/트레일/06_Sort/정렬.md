# 1. $O(N^2)$
## 1. Bubble sort

첫번째 와 두번째 값을 비교하고
두번째와 세번째 값을 비교하고,
... n-1번째와 n번째 값을비교합니다.

이 과정에서 순서가 맞지 않은 값을 서로 교환해줍니다.
이런 절차를 정렬이 될때 까지 반복합니다.



i , i+1 비교 반복 
swap 없을 때 까지 반복

while문

개선 버블

```python

def Bubble_sort(arr):
	n = len(arr)
	
	
	while True:
		swap = False
		
		for i in range(n-1):	
			if arr[i] > arr[i+1]:	
				# arr[i], arr[i+1] = arr[i+1], arr[i]
				tmp = arr[i]
				arr[i] = arr[i+1]
				arr[i+1] = tmp
				
				swap = True
			
		if not swap:
			break

	return arr
```

```python

def Bubble_sort(arr):
	n = len(arr)
	
	for i in range(n):
		for j in range(n-1):
			if arr[j] > arr[j+1]:	
				# python 에서만 가능
				# arr[j], arr[j+1] = arr[j+1], arr[j]
				tmp = arr[j]
				arr[j] = arr[j+1]
				arr[j+1] = tmp
	
	return arr

```





## 2. Selection sort

n 가장 작은거
n-1 가장 작은거


```python


def selection_sort(arr):

	len = len(arr)
	
	for i in range(len):

		# 가장 작은 인덱스 위치 찾기		
		idx_min = i
		for j in range(i+1):		
			if arr[j] > arr[idx_min]:
				idx_min = j
		
		arr[i], arr[idx_min] = arr[idx_min], arr[i]
	
	return arr
```


## 3. insert sort

앞에서 부터 순서대로 보면서
앞에 있는 모든 원가 정렬 되어 있다는 가정
하에서 현재 원소의 위치를 적절하게 집어넣는 정렬


```python


def insert_sort(arr):
	len = len(arr)
	
	for i in range(1, len):
		j = i-1
		key = arr[i]
		while j>= 0 and arr[j] > key:
			arr[j+1] = arr[j]
			j -=1
		
		arr[j+1] = key



```

삽입정렬을 할때 우리가 생각해야하는것은
앞에서 있는 것은 정렬되어 있고
그 다음이 어디 들어갈지 체크하는것이다.

그래서 i 번과 j = i-1 번을 비교해야한다.
여기서 키워드는 key를 주는 것이다.
