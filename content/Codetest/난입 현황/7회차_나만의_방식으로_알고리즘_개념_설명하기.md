## 1. 완전탐색

완전탐색하면 무엇이 떠오르시나요?

모든 것을 탐색한다.
backtracking이다.

많이 비슷합니다.
그래서 우리는 많이 헷갈입니다. 저도 그랬고 지금도 헷갈입니다. 
그렇게 다고 헷갈린다고 해서 포기하면 안되죠


### 1) 완전탐색(Exhaustive Search)

완전탐색 => 말 그대로 모든 부분을 탐색하는 것입니다.
그런데 어느곳에서는 찾아보면 brute-focre- search라고 하고 헷갈리죠
(추후 밑에서 설명해드릴겠습니다. )


먼저 영어로는 Brute-Force Search 이라고 하는데 
brute(난폭한, 짐승같은) Force(힘) Serach(탐색)

그냥 생각없이 처음부터 다 돌린다고 생각하면 되요

간단히 말해서 시간 복잡도를 잡고 진행할때 최악을 경우를 대비해서 진행하자나요
그 최악을 바탕으로 다 돌려버리는 거에요

1부터 100에서 무작위의 숫자가 빠졌다고 가정 하면 1~100 모든 숫자를 파악하는 거죠!!
즉 모든 경우의 수를 진행해보는 것에요


### 2) backtracking 

backtracking은 왔던 길을 되짚어가다. 돌아간다는 뜻입니다. 
알고리즘을 진행하는 과정에서 조건에 맞지 않으면 돌아가는 느낌이에요
가지치기 같은 느낌이라고 생각하면 되요!!
정확히는 직접 경험해봐야 안다는 느낌일까요
(어린아이가 불에 뜨겁다는 것을 직접 가까이 가보고 아는 것 처럼 가보고 아니니까 이길 안가 라는 느낌이에요)

backtracking은 완전탐색과 다르다고 생각하는 사람들도 있는데
완전탐색의 방법 중 하나가 backtracking이에요 구현 기법인 거죠

완전탐색의 알고리즘을 보면 여러가지의 종류가 있어요
부루트 포스. 백트래킹, 비트 마스크, 순열, 재귀함수, DFS, BFS 
하지만 우리는 코테를 풀때 완전탐색의 종류로 접근하는게 아니라

backtracking 알고리즘으로 접하다 보니 비슷한데 왜 이름이 다른지 하면서 헷갈릿때가 많습니다.
위에서 보셨다 싶이 같은 종류이기 때문입니다. 그래서 비슷한 내용이 많았던 것입니다.

### 2) 슈도코드
```
n 입력 받는다.
lst = n을 만큼 숫자를 입력받는다.

# 중복 없이 3개수를 구하는 방식
range(n):
range(i+1,n):
range(j+1,n):

조건문
1. 숫자로 접근한다.
2. char로 접근한다.

# 저번 문제를 풀때는 char로 접근헀기 때문에 이번에는 숫자로 접근하겠습니다.

우리는 1의 자리 조건 carry 인지 확인
우리는 2의 자리 조건 carry 인지 확인
우리는 3의 자리 조건 carry 인지 확인
우리는 4의 자리 조건 carry 인지 확인
우리는 5의 자리 조건 carry 인지 확인 

걸쳐서 False으면 answer 값과 숫자3개의 합 비교

answer이 따로 필요함
```

### 3) 코드 작성
저는 슈도 코드를 그대로 가지고와서 작성을 진행하는 편입니다.
``` python

# n 입력 받는다.
# lst = n을 만큼 숫자를 입력받는다.
n= int(input())
lst = [int(input()) for _ in range(n)]

# 중복 없이 3개수를 구하는 방식
# range(n):
#  range(i+1,n):
# range(j+1,n):

answer = -1
for i in range(n):
  for j in range(i+1, n):
    for k in range(j+1, n):
		
		carry= False
		
		# 조건문 숫자로 접근한다. O 
		# 우리는 1~1000의 자리 조건 carry 인지 확인
		if lst[i]%10 + lst[j]%10 + lst[k]%10 >=10:
		  carry = True

		if lst[i]%100//10 + lst[j]%100//10 + lst[k]%100//10 >=10:
		  carry = True
		  
		if lst[i]%1000//100 + lst[j]%1000//100 + lst[k]%1000//100 >=10:
		  carry = True
		
		if lst[i]%10000//1000 + lst[j]%10000/1000 + lst[k]%10000//1000 >=10:
		  carry = True
		
		# 걸쳐서 False으면 answer 값과 숫자3개의 합 비교
		if not carry:
		  answer = max(answer, lst[i] + lst[j] + lst[k])

print(answer)
```
